## 1. 一句话结论

该实验的数据完整性和统计执行符合预设协议；方向 PBI 视图 `V` 与 Anchor-PBI margin 视图 `A` 确实存在广泛且双向的非冗余未来真阳性信息，但现有动态 Hybrid 并没有稳定地把这种互补性转化为“同时优于两个单视图”的融合增益：40 个预设 Problem–M–Stage 单元中，Unique 条件有 33 个成立，Strict Fusion 条件只有 1 个成立，最终联合互补性也只有 1/40 成立。因此，本实验支持“双视图具有互补预测信息”和“Hybrid 机制确实在混合不同来源”，但不支持“混合 PBI 普遍有效”“动态权重因果优于固定权重”或“该模块提高最终 IGD/IGD+/HV”的结论。

## 3. 数据来源和统计单位

本报告读取并交叉核对以下表格：

| CSV | 行数 | 用途 |
|---|---:|---|
| `tables/GGP_FinalGate.csv` | 1 | 完整性总 gate |
| `tables/GGP_ComplementarityCoverage.csv` | 10 | 10 个 Problem–M 配置覆盖率 |
| `tables/GGP_ReplayEquivalence.csv` | 250 | 每个 replay 的搜索等价性 |

| `tables/GGP_UniqueContributionTests.csv` | 40 | 双向独有真阳性的 IUT |
| `tables/GGP_ComplementarityDecision.csv` | 40 | 预设联合科学判定 |
| 原实验 `GGP_PerRunStage.csv` | 24000 | H、V、A 等配额 Top-25% 的 Precision 等指标 |

正式 Primary 单位为：

- 10 个 Problem–M 配置；
- 每个配置 25 个固定独立 run；
- 每个 run 分 4 个 FE stage；
- 共 1000 个独立 run-stage 观测进入描述性汇总；
- 推断检验在每个 Problem–M–Stage 单元内以 25 个 run 为配对独立单位；快照先在 run 内聚合，未被伪装成独立重复。

Primary truth 是 `population_final`，即当前候选是否仍在 Hybrid 驱动轨迹的最终 Population 中。它是未来留存信号，不等价于“最终 Pareto 最优解”，更不等价于算法最终 IGD/HV。

### 4.2 该 gate 能证明什么

它证明当前 CSV 来自完整、可追溯、与原始正式搜索完全一致的 replay，且不存在缺失配置或失败 run 对结论的选择性影响。

## 5. 双视图是否真的互补

### 5.1 选择集合并不冗余

对 `population_final` 的 1000 个 run-stage：

- V/A 平均 Jaccard：0.2326；
- V/A 平均 Agreement：0.6830，但 Agreement 受到大量“两者都未选”候选影响，不宜单独作为互补证据；
- V-only 平均候选数：15.849/25；
- A-only 平均候选数：15.849/25；
- 因而每个视图平均约 63.4% 的 Top-25% 候选不在另一个视图的 Top-25% 内。

这说明 V 和 A 不是同一排序的轻微扰动，存在足够大的候选集合差异。

### 5.2 独有真阳性并非只是“候选不同”

在 1000 个 run-stage 中：

- V-only 至少出现一个未来真阳性：928/1000；
- A-only 至少出现一个未来真阳性：891/1000；
- 两个方向同时出现：873/1000；
- 两个方向都未出现：54/1000。

逐单元正式检验的结果为：

- 双向 success rate 都超过 0.5 的单元：35/40；
- 原始 `p_unique<=0.05`：34/40；
- 40 单元 Holm 校正后 `UniqueSupported=true`：33/40。

按 stage 分解：

| Stage | UniqueSupported | V-only run success rate 均值 | A-only run success rate 均值 |
|---|---:|---:|---:|
| S1 | 5/10 | 0.736 | 0.660 |
| S2 | 8/10 | 0.976 | 0.904 |
| S3 | 10/10 | 1.000 | 1.000 |
| S4 | 10/10 | 1.000 | 1.000 |

按问题分解：

| Problem | UniqueSupported |
|---|---:|
| DTLZ2 | 6/8 |
| DTLZ4 | 8/8 |
| DTLZ7 | 4/8 |
| WFG3 | 8/8 |
| WFG7 | 7/8 |

7 个未通过单元主要集中在早期阶段：DTLZ2-M10-S1、DTLZ2-M20-S1、DTLZ7-M10-S1/S2、DTLZ7-M20-S1/S2、WFG7-M20-S1。这意味着“双向独有信息”是广泛现象，但不是每个问题从预算初期就稳定成立。

### 5.3 独有贡献的大小

在有限值 run-stage 中：

- `MeanUniqueTPRateV` 平均约 0.183；
- `MeanUniqueTPRateA` 平均约 0.154；
- `MeanUniquePrecisionV` 平均约 0.292；
- `MeanUniquePrecisionA` 平均约 0.290；
- `MeanUniqueTPShare` 平均约 0.815。

`UniqueTPShare=0.815` 表明，在 V∪A 已覆盖的真阳性中，大部分真阳性只属于一个视图的 Top-25%，而不在两者交集中。这是当前实验对“两个视图具有互补预测信息”最有力的描述性证据之一。

需要注意：1000 个 `population_final` run-stage 中有 49 个 `UniqueTPRateV/A` 为 NaN，原因是对应聚合单位没有可作为分母的 truth positive；代码保持 NaN 而没有补零。正式 majority 检验使用非负的独有 TP 计数，不依赖这些比率的插补。

## 6. Hybrid 是否真正使用了两个来源

Hybrid 每次也选择 25 个候选。按 1000 个 `population_final` run-stage 平均分解：

| Hybrid 候选来源 | 平均候选数 | 占 Hybrid Top-25% |
|---|---:|---:|
| V∩A | 9.150 | 36.6% |
| V-only | 8.042 | 32.2% |
| A-only | 4.893 | 19.6% |
| V/A 均未选 | 2.916 | 11.7% |

Hybrid 的真阳性来源占比为：

- V∩A：32.3%；
- V-only：36.0%；
- A-only：17.9%；
- V/A 均未选：13.8%。

因此，Hybrid 并不是简单复制 V，也确实吸收了 A-only 区域的候选与真阳性。不过它更偏向 V-only：平均从 V-only 取约 8.04 个候选，从 A-only 取约 4.89 个候选。

同时，Hybrid 平均丢失 V 已识别真阳性 2.04 个、丢失 A 已识别真阳性 3.30 个。融合的净效果取决于“新增真阳性”是否能抵消这些损失；后面的严格融合检验显示，多数单元没有稳定抵消对每个 run 而言更好的单视图。

## 7. 严格融合增益：总体均值与逐单元结论不同

### 7.1 总体描述性均值

| View | `population_final` Precision@25% |
|---|---:|
| Hybrid | 0.28698 |
| V | 0.27748 |
| A | 0.27617 |

因此：

- Hybrid−V：+0.00950，即约 +0.95 个百分点；
- Hybrid−A：+0.01081，即约 +1.08 个百分点。

如果只看这三个总体均值，很容易得出“Hybrid 优于两个单视图”的印象。但这个结论不满足预设的严格问题，因为不同 run-stage 中表现更好的单视图会变化。

### 7.2 与每个 run-stage 中更好的单视图比较

定义：

`Delta_best = Precision_H − max(Precision_V, Precision_A)`。

结果为：

- 平均 `Delta_best=-0.02448`，即 Hybrid 平均低 2.45 个百分点；
- 1000 个 run-stage 中：310 胜、106 平、584 负；
- 含平局半权重的描述性 win probability 为 0.363；
- 40 个单元中只有 8 个 `MeanDeltaVsRunwiseBest>0`；
- 只有 1 个单元的未校正 paired bootstrap 95% CI 完全高于 0；
- 有 20 个单元的未校正 CI 完全低于 0；其余 19 个跨 0。

这些 CI 没有对 40 单元进行多重校正，因此“20 个负向 CI”只能作为强烈的描述性异质性信号，不能被写成 20 个正式多重校正后的负向发现。

### 7.3 预设 IUT + Holm 结果

Strict Fusion 要求同一单元内 H>V 和 H>A 的两个单侧 Wilcoxon 都成立，并使用两者 p 值最大值作为 IUT p 值，再对 40 个单元进行 Holm 校正。

- H−V 与 H−A 两个均值方向都为正：18/40；
- 原始 `p_fusion<=0.05`：8/40；
- Holm 后 `FusionSupported=true`：1/40；
- 与 Unique 条件取交集后 `ComplementaritySupported=true`：1/40。

唯一支持单元为 WFG3-M20-S1：

| 指标 | 数值 |
|---|---:|
| Mean Hybrid Precision | 0.10848 |
| Mean V Precision | 0.07968 |
| Mean A Precision | 0.06624 |
| H−V | +0.02880 |
| H−A | +0.04224 |
| H vs V paired win probability | 0.96 |
| H vs A paired win probability | 0.78 |
| H vs V rank-biserial | 0.951 |
| H vs A rank-biserial | 0.793 |
| `Delta_best` | +0.01760 |
| `Delta_best` bootstrap 95% CI | [0.00576, 0.02912] |
| `p_fusion_raw` | 0.000328 |
| `p_fusion_Holm` | 0.01314 |
| V-only success runs | 24/25 |
| A-only success runs | 25/25 |
| `p_unique_Holm` | 1.01×10^-5 |

这个单元构成了可信的局部正面证据：在 WFG3、M=20、预算早期 S1，Hybrid 同时优于两个等配额单视图，而且两个单视图也都提供独有真阳性。

作为敏感性检查，将 Fusion 与 Unique 的原始 IUT p 值先取最大值、再对 40 个“最终互补性”假设统一做一次 Holm，仍然只有该单元通过，调整后 p=0.01314。因此唯一正面单元不依赖“两个检验族分开校正”的实现选择。

## 9. 动态混合是否表现出预期的阶段转换

生产 Hybrid 使用连续 `score_v` 与二值 `label_dyn`：

`score_hybrid = (1-ratio)·score_v + ratio·label_dyn`。

但等配额 A 基线是连续 `anchor_margin` Top-25%，并不是二值 `label_dyn` 本身。因此，A 的独有贡献可以证明 Anchor-derived 信息与 V 不同，却不能被直接当成生产 Hybrid 的第二个连续输入。

CSV 中的集合重叠为：

| Stage | Jaccard(H,V) | Jaccard(H,A margin) | Jaccard(V,label_dyn) | Jaccard(H,label_dyn) |
|---|---:|---:|---:|---:|
| S1 | 0.5603 | 0.4376 | 0.3037 | 0.5474 |
| S2 | 0.5536 | 0.3850 | 0.3042 | 0.5345 |
| S3 | 0.5590 | 0.4085 | 0.3097 | 0.5443 |
| S4 | 0.5614 | 0.4085 | 0.3093 | 0.5440 |

这些重叠没有显示随 stage 单调地“从 V 转向 Anchor/label”的轨迹。该现象不能证明动态权重无效，因为 Top-25% 是非线性阈值操作，而且 A margin 与 `label_dyn` 不同；但它意味着当前 CSV 没有提供动态日程发挥预期阶段切换作用的直接证据。要检验这一点，必须加入 fixed-weight 与动态权重的独立消融轨迹。

## 11. “混合 PBI 作用”可以证明到哪一层

| 结论层级 | 证据状态 | 可辩护结论 |
|---|---|---|
| 代码机制被执行 | 支持 | Hybrid Catalog 与 `score_hybrid` Top-25% 完全一致；重放与原搜索完全等价 |
| 两个视图提供不同候选 | 强支持 | V/A Jaccard 低、各自约 15.85 个独有候选 |
| 两个视图提供不同未来真阳性 | 较强支持 | 33/40 单元通过双向 Unique IUT + Holm |
| Hybrid 确实吸收两个来源 | 描述性支持 | Hybrid 候选和真阳性均来自 V-only 与 A-only 区域 |
| Hybrid 总体平均优于某一个固定单视图 | 描述性支持 | H 平均分别高于 V、A 约 0.95、1.08 个百分点 |
| Hybrid 在每个场景同时优于两个单视图 | 不支持普遍结论 | 仅 1/40 单元正式支持；平均 `Delta_best<0` |
| 动态权重优于固定权重 | 未检验 | 没有 fixed-weight 对照 |
| 混合 PBI 导致最终优化性能提升 | 未检验 | 没有独立 H/V/A 算法轨迹的最终 IGD/IGD+/HV 对照 |
| 跨问题/PF 普遍鲁棒 | 反证信号明显 | WFG、尤其 WFG7 为负 |

因此，最准确的定位是：**该实验验证了双视图优质组识别信号的互补性，并发现一个局部严格融合成功单元；它没有验证当前动态融合规则的普遍优势。**

## 12. 统计方法审查

### 12.1 优点

- 独立单位正确：快照先聚合到 run-stage，25 个 run 才是推断单位；
- 三个视图在相同 Problem、M、stage、run、seed 下配对；
- Fusion 使用两个单侧 Wilcoxon 的 intersection-union test，必须同时胜过 V 和 A；
- Unique 使用两个单侧精确二项 majority test，也必须两个方向同时成立；
- 两个 Primary 检验族各自对 40 单元做 Holm FWER 校正；
- 输出均值差、中位数差、paired win probability、rank-biserial 与 bootstrap CI，而不是只输出星号；
- 250 个 run 无缺失、无失败、无只保留“成功实验”的 survivorship bias；
- Secondary truth 没有被混入 Primary 判定。

### 12.2 需要在论文中说明的限制

1. **On-policy 内生性（P0，若声称因果）**：未来 Population truth 来自 Hybrid 自己驱动的搜索轨迹。结果是预测关联与机制一致性证据，不是反事实因果证据。
2. **缺少算法级对照（P0，若声称性能提升）**：没有 V-only、A/label-only、fixed-weight、dynamic-weight 的独立完整搜索轨迹，不能归因最终 IGD/HV。
3. **基线与真实混合输入不完全同构（P1）**：A 基线为连续 `anchor_margin` Top-25%，生产 Hybrid 的第二项为二值 `label_dyn`。应使用“Anchor-derived view”而不是“两连续 PBI 分数线性融合已被证明”。
4. **总体均值掩盖异质性（P1）**：DTLZ 为正、WFG 为负；不得只报告总体 H>V/A。
5. **Unique majority 是事件概率而非贡献大小（P1）**：一个 stage 内只要出现一次独有 TP 就计为成功。应同时报告 success rate、UniqueTPRate 和 UniquePrecision。
6. **bootstrap CI 未做跨 40 单元校正（P1）**：CI 只作描述，不应替代 Holm 后的 Primary 判定。
7. **Wilcoxon 的位置差解释（P2）**：signed-rank 检验针对配对差的秩/位置变化，并不等价于均值差检验；当前代码额外要求均值方向为正，论文应同时报告检验与效应估计。
8. **49 个 rate 缺失值（P2）**：其来源是分母为零，处理方式合理，但应在统计方法中明确说明 `NaN` 不补零。
9. **两个检验族的最终联合错误率（P1）**：当前 Fusion 与 Unique 分开 Holm 后取交集。建议附带报告“先合成最终 IUT、再统一 Holm”的敏感性分析；本数据下结论仍为同一个 1/40 单元。

## 14. 推荐的论文结论表述

### 14.1 可以直接使用的谨慎版本

> 在冻结且经搜索等价性验证的 Hybrid 轨迹上，方向 PBI Top-25% 与 Anchor-PBI margin Top-25% 呈现广泛的候选集合差异，并在 33/40 个 Problem–M–Stage 单元中同时表现出超过半数独立运行的双向独有未来真阳性贡献。该结果支持两个视图包含非冗余的优质组识别信息。生产 Hybrid 的总体 `population_final` Precision 略高于两个单视图的总体均值，但在预设的严格同时优于两者检验中，仅 WFG3-M20 的早期阶段通过 Holm 校正。因此，现有证据支持双视图互补性及一个局部融合优势，不支持动态 Hybrid 在所有问题和阶段普遍优于单视图。

### 14.2 不应使用的表述

- “实验证明动态混合 PBI 优于固定 PBI”；
- “混合 PBI 显著提高了最终 IGD/HV”；
- “Hybrid 在所有 DTLZ/WFG 和不同 PF 上都鲁棒”；
- “33/40 个 Unique 单元证明 Hybrid 融合有效”；
- “Final gate PASS 证明科学假设成立”；
- “总体平均 Precision 更高，因此 Hybrid 在每个场景都更优”。

## 15. 下一步最小充分实验

若目标是把“互补信息存在”推进到“动态混合 PBI 有因果性能价值”，建议按以下顺序补充：

1. **精确融合消融**：在完全相同的 DataProcess、旧 `p_err`、`lambda_t`、网络、候选路由和 seed 下，比较 V-only、label/Anchor-only、固定权重 `{0.25,0.5,0.75}`、当前动态权重。
2. **独立搜索轨迹**：每个变体必须实际驱动自己的后续搜索，不能只在 Hybrid 轨迹上离线打分。
3. **算法级 Primary**：预先指定最终 IGD/IGD+/HV 中的一个主指标，其余作为 Secondary；按相同 seed 配对并进行多重校正。
4. **候选成功率**：记录各视图提出的候选最终是否被真实评估、是否进入 Population/Archive，以及对下一阶段 IGD+ 的实际贡献。
5. **动态对固定的直接门槛**：必须证明 dynamic 同时优于最佳预设 fixed weight，而不是只优于 V-only 或 A-only。
6. **针对 WFG7 的失配诊断**：检查 `score_v` 连续尺度与二值 `label_dyn` 的混合尺度、正例比例、候选来源和错误回退；任何 rank normalization/calibration 改动都应作为独立可逆变体。
7. **外部泛化验证**：关系样本按 solution/group 划分，互为反向的 pair 保持在同一 fold，避免 relation-pair 泄漏。

在这些实验完成前，当前结果最适合作为“机制互补性补充证据”和后续融合改进的诊断依据，而不是最终算法性能证明。
