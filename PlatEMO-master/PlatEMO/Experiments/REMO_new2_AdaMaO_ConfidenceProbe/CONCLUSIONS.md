# ConfidenceProbe 实验总结论（v1 + v2 合并分析）

- 撰写日期：2026-07-28
- 覆盖实验：v1（Pareto 主判据，`screening`/`confirmation`）、
  v2（SDE 主判据，`screening_sde`/`confirmation_sde`），
  共 4 个 profile × 50 run = 200 次独立运行，全部 completed 且通过全量校验。
- 研究问题：AdaMaO（REMO_new2_AdaMaO_SDEOnly）中 HybridPBI_Classification
  输出的 PBIConfidence 越高，PBI 关系预测是否越可靠？是否值得据此开发置信度门控？

## 3. 现象与结论

### 现象 1：高维下支配型真值系统性不可测（v1 失败的根因）

- v1 M=10：WFG3/WFG7 各约 20.1 万个 good-rest 对中，严格 Pareto 可比对为 **0**；
  50 个 run 仅 16 个能同时算出 Q1/Q5/差值/AUROC。
- v1 M=20：DTLZ7、WFG3、WFG7 可比对全部为 0；DTLZ2 仅 44 对。
- v2 的 ε-支配辅助真值定量补充：即使放宽到 ε=0.10（归一化目标的 10%），
  WFG7 在 M=10 仅 1693/201000（0.8%）可比，M=20 仅 1070/201000（0.5%）。

**结论 1**：在 M≥10 的昂贵场景下，以支配关系（严格或 ε 放宽）为真值的
代理模型评价判据整体不可行；这不是实现缺陷，而是高维目标空间中可比对
消失的必然结果。v1 判 INSUFFICIENT_DATA 是协议正确阻止了在残缺数据上下结论。
该发现本身具有方法学价值，并直接论证了 v2 改用 SDE 一致性真值的必要性。

### 现象 2：非退化问题上置信度判别能力大、单调、run 级零例外（v2 主结果）

v2 各问题 SDE 错误率（Q1→Q5 为置信度最低→最高箱）：

M=10（每问题约 20.1 万对，每格均为 10 个 run 汇总）：

| 问题  | Q1    | Q2    | Q3    | Q4    | Q5    | Q5−Q1           | 95% CI           | AUROC           |
| ----- | ----- | ----- | ----- | ----- | ----- | ---------------- | ---------------- | --------------- |
| DTLZ2 | 38.3% | 38.1% | 29.8% | 23.1% | 18.1% | −20.2pp         | [−22.9, −17.5] | 0.610           |
| DTLZ4 | 34.0% | 25.6% | 17.5% | 10.6% | 5.4%  | −28.5pp         | [−30.7, −26.3] | 0.706           |
| DTLZ7 | 37.2% | 36.8% | 33.3% | 28.3% | 20.2% | −17.0pp         | [−18.1, −15.9] | 0.562           |
| WFG3  | 39.5% | 57.5% | 52.2% | 50.6% | 47.1% | **+7.6pp** | [+2.2, +13.1]    | **0.464** |
| WFG7  | 33.5% | 33.2% | 27.3% | 24.2% | 21.4% | −12.0pp         | [−14.3, −9.4]  | 0.537           |

M=20：

| 问题  | Q1    | Q5    | Q5−Q1           | 95% CI           | AUROC           |
| ----- | ----- | ----- | ---------------- | ---------------- | --------------- |
| DTLZ2 | 39.4% | 19.2% | −20.2pp         | [−23.7, −16.2] | 0.611           |
| DTLZ4 | 49.5% | 8.1%  | −41.3pp         | [−46.9, −36.1] | 0.751           |
| DTLZ7 | 45.4% | 33.9% | −11.6pp         | [−14.0, −8.9]  | 0.543           |
| WFG3  | 46.3% | 48.2% | **+1.9pp** | [−1.6, +6.0]    | **0.468** |
| WFG7  | 36.8% | 30.3% | −6.5pp          | [−10.3, −2.3]  | 0.491           |

run 级方向一致性（Q5 错误率低于 Q1 的 run 数）：
M=10 时 DTLZ2/4/7、WFG7 均为 **10/10**，WFG3 仅 3/10；
M=20 时 DTLZ 三个 10/10，WFG7 8/10，WFG3 4/10。

**结论 2**：在非退化前沿问题上，PBIConfidence 对关系预测可靠性的判别能力
真实、稳定且效应量大（12~41pp），错误率沿五个置信箱基本单调下降，
40 个 run 无一例外。v2 是预注册 + 全新种子的验证性实验，
M=10 主门槛正式通过（GATE_DEVELOPMENT_VALUE），
"值得开发置信度门控"由此获得验证性证据。

### 现象 3：效应跨种子精确复现（v1 辅助 vs v2 主判据）

v1（旧种子）的 SDE 辅助指标与 v2（新种子）的 SDE 主判据逐问题对照：

| 问题  | M=10 Q5−Q1：v1 → v2 | M=10 AUROC：v1 → v2 | M=20 AUROC：v1 → v2 |
| ----- | --------------------- | -------------------- | -------------------- |
| DTLZ2 | −21.3pp → −20.2pp  | 0.609 → 0.610       | 0.605 → 0.611       |
| DTLZ4 | −29.9pp → −28.5pp  | 0.714 → 0.706       | 0.718 → 0.751       |
| DTLZ7 | −16.5pp → −17.0pp  | 0.551 → 0.562       | 0.548 → 0.543       |
| WFG3  | +3.7pp → +7.6pp      | 0.472 → 0.464       | 0.461 → 0.468       |
| WFG7  | −10.3pp → −12.0pp  | 0.538 → 0.537       | 0.501 → 0.491       |

**结论 3**：两批完全独立的种子给出逐问题几乎相同的效应量与排序，
说明测得的是问题的稳定属性而非随机波动。这也事后印证了
v2 换真值重跑（而非在旧数据上升级辅助判据）的方法学谨慎并没有翻转结论，
但使结论具备了验证性效力。

### 现象 4：WFG3 系统性反向，且呈"Q1 异常好 + Q2 最差"的倒 U 形

WFG3 在三批独立证据（v1 旧种子、v2 新种子 M=10、v2 M=20）中
AUROC 全部落在 0.46~0.47，方向反转。其分箱曲线并非单调反向：
Q1 异常地好（39.5%），Q2 最差（57.5%），Q2→Q5 递减但 Q5（47.1%）仍差于 Q1。
v2 的 ε-支配辅助真值下同样反向（M=10 ε=0.05 时 +41.1pp），
排除了"SDE 真值伪影"的解释。

**结论 4**：WFG3（退化前沿）上 PBI 置信度**结构性失效**是确凿、可复现的现象。
倒 U 形说明失效不是"置信度退化为噪声"（那样曲线应平坦），而是置信度机制
在退化几何上发生了结构性错位——最低置信箱反而圈出一批 PBI 方向假设
仍成立的关系对。任何置信度门控都必须为此类几何准备回退机制；
该现象的机理（推测与退化前沿破坏 PBI 参考方向假设有关）值得单独实验查明。

### 现象 5：问题异质性随维度增大而加剧，导致 M=20 门槛惜败

M 从 10 → 20：DTLZ4 效应从 −28.5pp 增强到 −41.3pp，DTLZ2 持平；
而 WFG7 的 AUROC 从 0.537 跌到 0.491（不再显著），WFG3 维持反向。
问题等权聚合下 AUROC CI 下界从 0.507 降至 0.495，仅此一条门槛未过
（差值门槛 −0.040<0 与方向门槛 4/5 均通过，绝对下降 15.5pp 甚至大于 M=10）。

**结论 5**：置信度有效性本身对维度增长稳健（四个非退化问题在 M=20
全部保持负方向），但**有效性的问题间差异随维度加剧**：DTLZ 家族增强、
WFG 家族恶化。按冻结协议，M=20 的正式结论是"未通过"；
其科学解读不是"效应消失"，而是"有效性由问题几何决定，且几何的影响
随维度放大"。汇报与论文中两者都应如实呈现。

### 现象 6：网络置信度在全部 10 个问题×M 组合上有效，与 PBI 置信度失效模式不相关

NetworkConfidence 的 SDE-AUROC：M=10 为 0.61~0.67，M=20 为 0.60~0.65，
**包括 WFG3（0.613/0.598，v1；0.604/0.599，v2）**。两版实验一致。

**结论 6**：网络置信度是更稳健但判别力上限较低的信号（AUROC 不超过 0.67，
低于 PBI 置信度在 DTLZ4 上的 0.75），且在 PBI 置信度反向的 WFG3 上依然有效。
两者失效模式互补，构成门控"主信号 + 回退信号"的天然架构。

### 现象 7：置信度兑现为"解的命运"，但不兑现为"候选的 IGD 价值"

- 解级（v2 两个 M 一致）：高置信 rest 解的 H3 存活率差 −9.3pp/−7.3pp
  （4/5 问题方向正确）——算法确实按置信度淘汰了该淘汰的解；
  高置信 good 解进入最终前沿率 +2.2pp（弱正，3~4/5 问题）。
- 候选级：NetworkConfidence 与边际 IGD 改进、下代进档率的关联在 ±1pp 内，≈0。

**结论 7**：置信度的可用价值在**关系过滤层**（哪些比较可信），
不在**候选价值预估层**（哪个解值得真实评估）。门控开发应做成
"高置信关系才参与筛选决策"，而不应尝试用置信度挑选候选解。

## 4. 总结论

> 两版共 200 run 的预注册实验链条证明：(i) 以支配关系为真值的代理模型
> 评价判据在 M≥10 不可行（v1 的方法学发现）；(ii) 换用 SDE 一致性真值后，
> PBI 置信度在非退化前沿问题上对关系预测可靠性具有大而稳定、跨种子
> 精确复现、随维度不衰减的判别能力（错误率绝对下降 12~41pp），
> M=10 主门槛正式通过；(iii) 其有效性存在由问题几何决定的系统性边界——
> 退化前沿的 WFG3 三批数据一致反向，并使 M=20 门槛以 0.005 之差未通过；
> (iv) 网络置信度无此缺陷但判别力上限较低。
> 因此置信度门控**值得开发**，且架构应为：基于 PBI 置信度的关系级过滤
>
> + 网络置信度回退兜底，不做候选级价值预估。

## 5. 对门控设计的具体启示

1. **作用层**：只过滤 PBI 关系预测（good-rest 比较），不选候选解（结论 7）。
2. **阈值形态**：错误率沿分箱单调下降（结论 2），支持分位数式阈值
   （如仅信任前 40% 置信度的关系），而非全局固定阈值。
3. **回退**：低置信或疑似退化几何时回退到网络置信度/保守模式（结论 4、6）。
4. **风险问题**：WFG3 型退化前沿是已知失效场景，对比实验必须包含它，
   并把"门控在 WFG3 上不劣于无门控"作为安全性验收条件。

## 6. 局限与效度威胁

- M=20 未通过冻结门槛，开发绿灯正式依据是 M=10 screening；
  M=20 作为部分支持证据（2/3 门槛通过）呈现，不得表述为"全部通过"。
- SDE 一致性真值与算法自身的存活准则同源，存在循环性质疑；
  缓解证据：ε-支配真值在可测处与 SDE 方向一致（DTLZ 家族全部为负），
  且候选级 IGD 指标独立采集。
- 问题池仅 5 个基准问题、2 个 M 档位；WFG 家族仅 2 个代表，
  "退化前沿导致反向"的归因目前是基于几何特征的合理推测，未经机理实验证实。
- v1 的 SDE 数字在设计 v2 前已被观察过；v2 的验证性效力来自新种子，
  但真值选择本身受过旧数据启发，这一点在论文中应披露。
