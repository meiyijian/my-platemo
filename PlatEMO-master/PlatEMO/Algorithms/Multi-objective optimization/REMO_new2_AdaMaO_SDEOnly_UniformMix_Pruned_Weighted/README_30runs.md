## 跳过与续跑规则

检查文件中的 SOLUTION 种群、目标数、实际决策维数、有限值、最终 FE、FE 序列及存在的元数据。元数据中算法、问题、参数、N、M、D、预算或运行编号不一致，不能作为本次完整结果。

历史文件可能没有逐次参数、种子和源码哈希。本脚本按照既定算法目录及本次已核对的历史配置复用它们，清单明确标为 `legacy-unverified`，不宣称完成全部历史溯源。相同运行编号也不代表共同随机种子，后续不能直接按配对实验处理。

REMO/CSEA 保留原代码的末批超预算行为，接受最终 FE 在 300–399 内的结果，并逐文件记录实际 FE。该范围用于排除明显不同预算的文件，不证明其原始配置；元数据若明确 maxFE 不是 300 则拒绝。其余算法要求最终 FE=300。实际超预算次数须在后续论文统计中披露，不能称为所有运行严格等 FE。

每次成功运行先保存完整种群到临时文件，再计算 IGD，校验后发布为正式文件。IGD 计算失败但种群完整时保留结果并记下错误，续跑不会因此重做优化；可从种群补算指标。本脚本不计算高维 HV，不导出论文统计表。

损坏或设置不符的历史文件不覆盖，新结果放同算法的 `supplement30` 子目录；清单记录实际采用路径。若补充目录自身也有不完整文件，先停止并提示人工检查，以免覆盖恢复材料。

中断后再次执行相同命令，重新清点并补缺。任务失败写入独立日志，其他任务继续；进程池故障可能中断本次运行，但已保存结果仍可复用。

## 并行与记录

默认最多同时运行 2 个任务，可把命令末尾的 `2` 改为 `4` 或 `6`。已有进程池会复用，并限制本脚本的同时任务数；已有线程池不兼容，需要在空闲 MATLAB 会话中运行。脚本不删除用户现有进程池。

每个工作进程显式配置本地 PlatEMO 路径，每个任务优先使用目标算法目录。参数显式传入。新增运行在直接调用 Solve 前设置独立全局种子，绕过 platemo 入口的 rng('shuffle')。Weighted 为兼容旧十/二十目标运行，模式流 run 固定为 1，全局种子随问题、目标数和运行编号变化；这不意味着跨算法已有数据是配对实验。

`diagnostics/paper_30runs` 保存：

- `inventory_latest.csv` 以及带时间戳清单，逐文件记录复用、待跑、冲突、实际 FE 和溯源状态。
- `sources_*.mat`，本次配置及算法目录内源文件哈希；不是整个依赖闭包，也不能追溯缺少元数据的历史文件。每次新增运行前核验对应算法源文件未变。
- `run_*.log`，本次运行进度。
- 每次失败对应的错误日志。

运行中不要同时启动另一个本脚本实例或修改算法。`RUNNING.lock` 防止重复启动，正常结束或 MATLAB 中断会清理。若 MATLAB 被强制结束，确认所有旧任务已停止后，手动删除本目录 `diagnostics/paper_30runs/RUNNING.lock`，再续跑。
