## 一、PC-SAEA 相对 REMO 到底改了什么(代码级对照)

| 环节         | REMO (TEVC 2022)                         | PC-SAEA (SWEVO 2023)                                                                                                                               |
| ------------ | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 标签来源     | 与 k=6 个参考解做 PBI 比较 → 好/坏两类  | 标量适应度`Fitness = rate·R + (1-rate)·D`:R=支配强度(收敛),D=SDE 空间密度(多样性),rate=FE/maxFE 随进程增大 → **标签语义随搜索阶段漂移** |
| 训练对构造   | 好/坏类别间全配对,3 类标签(+1/0/-1)      | 按适应度排序,**只取最好 1/4 与最差 1/4,丢弃中间一半** → 天然类平衡 + 剔除边界模糊标签;边界带 Pmid 留作拒识参考                              |
| 分类器       | 3 隐层 MLP(patternnet,宽度∝2D),每代重训 | **PNN(newpnn)**:核密度记忆型分类器,"训练"即存储,单超参 spread,每代成本极低                                                                   |
| 预测可靠性   | 全局标量 p_err 校正投票,单条预测不做校验 | **双向反对称一致性检验**:同时预测 (x,ref) 与 (ref,x),若两方向结论不满足反对称 → 判为不可靠(输出 1.5)拒识                                    |
| 模型失效处置 | 无                                       | Error1 好→正常用;**Error2 好(模型系统性反了)→取反用**;都不好→随机回退                                                                     |
| 候选选择     | GA 内循环 + 投票分数                     | GA 内循环 + 标签分数,0.95 硬阈值截取                                                                                                               |
| 环境选择     | RefSelect                                | SPEA2 + 截断                                                                                                                                       |

结论:机械上确实是"换标签 + 换分类器 + 加一个一致性检验",你的直觉(改动不大)没错。

## 二、它能投一区的真正原因(可迁移的 4 条)

1. **诊断驱动的叙事骨架**。论文先诊断前代(REMO/CSEA 这类分类型 SAEA)的三个可指认缺陷——标签噪声(边界解误标)、类不平衡、预测无可靠性控制——然后每个机制一一对应一个缺陷,每个机制配一个消融。审稿人看到的不是"我们改了三处",而是"问题→机制→证据"的闭环。**一区评的是诊断的清晰度和证据链的完整度,不是改动量。**
2. **一句话能说清的原理性亮点**。"成对比较器必须反对称;违反反对称 = 认知不确定 → 零成本拒识"——不需要额外模型、适用于任何成对代理、一张图就能讲明白。再加一个反直觉彩蛋:"系统性错误的分类器取反后仍然有信息量"。审稿人对这种"小而干净、可泛化"的原理点的偏好,远高于大而糊的系统工程。
3. **阶段自适应的标签语义**。rate 权重把"模型该学什么"和"搜索进行到哪"绑定,静态分类器变成阶段感知的偏好模型——给论文提供了第二个概念层。
4. **SWEVO 级实验机器 + 团队生态**。DTLZ/WFG/MaF + 实际问题、K-RVEA/KTA2/CSEA/REMO 等全线对比、逐组件消融、运行时间分析(PNN≪MLP≪Kriging)、参数敏感性;作者是 PlatEMO 团队(Ye Tian/Xingyi Zhang),代码随平台发布。信誉和可复现性本身就是录用权重。

> 对你的直接启示:你不需要更大的改动,你需要 **(a)一个前代确实存在、且你能用数据演示的缺陷诊断;(b)一个一句话说得清的原理点;(c)每个机制配消融的证据链**。而你手里已经有一样 PC-SAEA 都没有的东西:一个 200-run 预注册的可靠性测量实验。

## 三、REMO 与 PC-SAEA 在 M=10~20 的缺陷清单(你的攻击面)

**D1 监督坍缩(REMO 的根伤,你已有实锤)**
你的 v1 探针:M=10 时 WFG3/WFG7 约 20.1 万个 good-rest 对中严格 Pareto 可比对为 **0**;M=20 时 DTLZ7 也归零;ε=0.10 放宽后 WFG7 仍只有 0.5~0.8% 可比。⇒ M≥10 时支配关系基本不再提供监督信号,一切标签只能来自标量化;而 REMO 用 6 个参考解的 PBI 划类,在 (M-1) 维前沿上覆盖率趋近于零,边界解大面积误标。

**D2 标签噪声是结构化的,却被同等对待(REMO 与 PC-SAEA 共有)**
你的 v2 探针:关系预测错误率沿 PBI 置信度五分箱单调下降,Q5−Q1 达 −12~−41pp,40/40 run 无一例外。⇒ 噪声标签在训练前就可识别,但 REMO/PC-SAEA 都把所有对等权喂给模型。

**D3 预测级可靠性:REMO 没有;PC-SAEA 有,但是未经验证的启发式**
PC-SAEA 的 delta=0.8、0.95 硬阈值、反对称检验,全文没有测量过"这个可靠性信号与真实错误率是否相关"。你恰好有测量这件事的全套预注册管线——**别人拍脑袋的地方,你有 200 run 的校准数据**。

**D4 PC-SAEA 的阶段自适应标签在高 M 下自我坍缩(可演示的新攻击点)**
`CalFitnessPC` 的 R 项 = SPEA2 支配强度。当种群互不支配(你的探针已证明 M≥10 常态如此),S≡0 → R 全同 → 归一化除以 0 → NaN,排序退化为按原始下标取前 1/4。也就是说 **PC-SAEA 引以为傲的"rate 越大越重收敛"在 M=10~20 名存实亡**。另有一个 PlatEMO 实现层疑点:D 项对标量 SDE 列向量取余弦距离,正数标量间余弦距离恒为 0,D 疑似恒等于 0.5(常数)。两点都可以用半天的脚本验证(见 N5),验证通过就是论文引言里的一张诊断图。

**D5 退化前沿使参考方向类可靠性信号反向(你的三次独立复现)**
WFG3 上 PBI 置信度 AUROC 0.46~0.47、倒 U 形,v1 旧种子/v2 新种子/M=20 三批一致,ε 真值下同样反向。REMO/PC-SAEA 及其后续都不知道自家信号存在这条几何失效边界。**知道失效边界并为它设计回退,本身就是别人没有的贡献。**

## 四、你手里已有的牌(现状盘点)

已实现(对应 D1/D2/D4 的机制):

- **M1 高维混合标签**:`HybridPBI_Classification` = 自适应参考解数 k_eff=max(6,⌈1.5M⌉) + 高维时用非支配解 K-means 的数据自适应方向场 + 连续 PBI 得分与二值锚点标签按 α=1−ratio 阶段融合 → 直接回应 D1。
- **M2 可靠性自适应关系训练**:conservative / curriculum(留最高置信 80%)/ weighted(置信度加权)三模式按 prev_p_err、mean_conf、coverage 路由 → 直接回应 D2;固定模式消融 arms(UniformMix_Original/_Weighted/_Curriculum)已建好。
- **M3 双异构代理 + 候选策略**:关系网(参考相对偏好)+ SDE 指标 SVR(Lp 形状自适应的收敛-多样性合成),uniform_mix 以 p=0.5 随机二选一;AlwaysIndicator/AlwaysExplore/LinearSchedule 消融 arms 已建好 → 回应 D4。
- **在线诊断量**:`RuntimeDiagnostics` 已计算 coverage(方向占用率)与 **degeneracy(目标矩阵 SVD 能量集中度)——这就是现成的退化前沿检测器**,目前只用于模式路由,还没接到 D5 的回退上。

已有证据(全领域独一份):

- 200-run 预注册探针,结论 1~7(监督坍缩、置信度单调有效、跨种子精确复现、WFG3 反向、网络置信度全域稳健、置信度只在关系层有价值)。

软肋(审稿人会打的地方):

- 模式路由的魔法阈值(tau_err=0.35、conf≥0.55、coverage<0.60)缺辩护 → 探针结论 2 恰好支持改为分位数式;
- p=0.5 的均匀混合"看起来像没想法" → 需要原则化包装(N4);
- 预测级可靠性机制缺位(PC-SAEA 有,你没有)→ N1/N2 补上,而且是"验证版";
- WFG3 失效是已知风险但还没变成机制 → N1 的回退分支。

## 五、论文故事主线(三幕结构)

**一句话定位:第一个把关系代理的"可靠性"从启发式假设变成预注册测量、并按测量结果分层设防的昂贵超多目标(M=10~20)优化算法。**

- **第一幕·高维监督坍缩(动机,方法学发现)**:M≥10 时支配可比对消失(E1 图),REMO 的参考类别标签覆盖坍塌,PC-SAEA 的支配强度项归零、阶段自适应失效(E2 图)。⇒ 高维昂贵优化里,关系代理的瓶颈不是分类器,而是**监督信号本身的可得性与可靠性**。
- **第二幕·可靠性是可测量的(探针,E3/E4 图)**:PBI 双表征一致性对关系错误率的判别力大、单调、跨种子复现(−12~−41pp);但存在几何边界——退化前沿上系统性反向;网络置信度无此缺陷但上限低。⇒ 可靠性信号必须"测过再用、失效有兜底"。
- **第三幕·把测量转化为机制(算法)**:标签层 M1(高维混合标签)→ 训练层 M2(可靠性自适应关系训练)→ 预测层 N1+N2(经校准的置信度门控 + 双向一致性,退化几何检测触发网络置信度回退)→ 仲裁层 M3/N4(双异构代理,候选级无可用信号 ⇒ 均匀随机对冲)。

这个结构完整复刻了 PC-SAEA 的"诊断→机制→证据"骨架,但每一环都比它多一层:**它的诊断是叙述,你的诊断是预注册实验;它的可靠性是阈值启发式,你的是校准过的信号 + 已知失效边界 + 回退。**

## 六、新增创新点(按性价比排序,全部可执行)

### N1 经验证的置信度门控关系过滤 + 网络置信度回退(核心新机制,~1 周)

设计已写在 CONCLUSIONS §5,直接落地:

- **作用层**:只过滤 good-rest 关系对/关系投票(结论 7:置信度不用于选候选)。
- **阈值形态**:分位数式(如只信任置信度前 40% 的关系),不用全局固定阈值(结论 2 的单调性支持)。
- **回退**:`degeneracy` 检测器(已在 `RuntimeDiagnostics` 里)超阈 或 PBI 置信度分布压缩(WFG 家族特征:均值 0.05~0.3)时 → 切换网络置信度(结论 6:全部 10 个问题×M 有效,含 WFG3)。
- **安全验收**:WFG3 上门控版不劣于无门控版(预注册为验收条件写进论文,这个写法本身就是加分项)。
- 实现:新建 `REMO_new2_AdaMaO_SDEOnly_UniformMix_Gated`,改动集中在 ModeBase 的关系对构造与 model_select 投票两处。

### N2 双向一致性信号——PC-SAEA 反对称检验的"校准版"(~3 天)

你的 `model_select` 已经为每个候选同时构造 [C1,Xi]/[Xi,C1]/[C2,Xi]/[Xi,C2] 四向预测,目前只做平均。升级:正反两向预测若违反反对称 → 该锚点的投票降权(软门控,不学 PC-SAEA 硬丢弃)。**关键差异化:用现成探针管线给一致性信号补测一个 AUROC(一致性 vs 关系错误率),做成"结构派生的零成本不确定性,且经过校准"**——这是对 PC-SAEA 那个亮点的正面回应与超越,审稿人一眼能看懂你和它的关系。

### N3 方法学贡献独立成文(写作,0 实现)

"支配真值在 M≥10 不可行 + SDE 一致性真值协议 + 预注册两阶段判据"写成论文的动机小节(或独立短文)。这是 REMO/PC-SAEA 系全线没有的东西,也顺带解释了你为什么不用他们的验证方式。

### N4 uniform_mix 的原则化包装(写作,0 实现)

不要说"随机 0.5"。说法:两个专家(参考相对偏好 / SDE 整体排序)的相对可靠性依问题与阶段而变;**我们测过候选级在线仲裁信号——不存在**(结论 7:置信度与边际 IGD 关联≈0);在无可用在线信号时,贪心仲裁与固定日程都会过拟合,均匀随机混合是零信息下的极小极大对冲;固定模式消融(AlwaysIndicator/AlwaysExplore/LinearSchedule 各自在某些问题/阶段失效)为证据。→ "我们试图做自适应、用实验证明了没有信号、于是选择诚实的对冲"——这个论证方式罕见且扎实。

### N5 PC-SAEA 高维标签坍缩展示实验(半天脚本,引言图)

脚本:LHS 采样(或跑 PC-SAEA 前几代)→ 对 M∈{3,5,10,15,20} 统计 (a) 种群非支配比例;(b) R 项方差/NaN 发生率;(c) D 项是否恒常数(PlatEMO 实现疑点,展示前以论文公式为准重核)。产出一张"PC-SAEA 标签信息量随 M 消失"的诊断图,与 E1(可比对消失曲线,数据已有)并排放在引言。
