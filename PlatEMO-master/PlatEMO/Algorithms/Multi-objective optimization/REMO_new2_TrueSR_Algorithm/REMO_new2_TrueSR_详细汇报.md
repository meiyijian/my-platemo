# REMO_new2_TrueSR 算法详细汇报

## 1. 算法概述

**算法全称：** REMO_new2_TrueSR — 基于真实软成对排序的代理辅助多目标优化算法

**名称由来：**
- REMO = Relation-based Evolutionary Multi-objective Optimization（基于关系学习的进化多目标优化）
- new2 = 改进版本 2
- TrueSR = True Soft Ranking（真实软排序）

**算法定位：** 面向昂贵多目标/高维目标优化的代理辅助进化算法，适用于每次目标函数评估耗时极长（数小时甚至数天）的工程场景。

---

## 2. 研究动机

### 2.1 昂贵优化的核心矛盾

在昂贵多目标优化中，真实评估次数极其有限（通常只有数百次），但搜索空间往往很大。传统的多目标进化算法（如 NSGA-II、MOEA/D）需要数万次评估才能收敛，直接使用不现实。

### 2.2 代理辅助方法的两条路线

| 路线 | 代表方法 | 思路 | 问题 |
|------|---------|------|------|
| 回归型 | K-RVEA, GPR | 直接预测目标函数值 | 多目标间存在冲突，回归误差累积 |
| 分类型 | CSEA, REMO | 判断解的好坏/相对关系 | 硬标签损失信息，边界噪声大 |

### 2.3 REMO 的关系学习框架

REMO 提出了"关系学习"路线：不直接预测目标值，而是训练一个关系模型来判断两个解之间的相对优劣。这种方法的优势在于：

1. 避免了多目标回归的误差累积
2. 代理模型只需辅助筛选，不需要精确拟合目标函数
3. 成对比较天然适合排序任务

### 2.4 REMO_new2_SR 的遗留问题

旧版 `REMO_new2_SR` 虽然引入了"软关系"概念，但存在三个关键缺陷：

**缺陷一：中间解被错误归类。** 旧逻辑将前 25% 标为好解（`true`），其余 75% 全部标为坏解（`false`），导致中间 50% 的优质解被错误训练为"坏解"。

**缺陷二：软标签受硬分类限制。** 虽然用 Sigmoid 生成了连续概率，但配对来源仍依赖硬分类的 `Catalog`（好类 vs 坏类），没有利用全排序信息。

**缺陷三：锚点选择偏向精英。** 只与最优 K 个锚点比较，使模型过度偏向利用（exploitation），降低探索性。

### 2.5 TrueSR 的改进目标

TrueSR 的核心目标是：**在保留 REMO_new2 hybrid PBI 评分框架的基础上，将"硬分类关系学习"升级为"真实软排序学习"**，让代理模型学习"解 A 比解 B 好多少"的连续概率，而不只是"解 A 好不好"的二分类标签。

## 3. 核心方法

### 3.1 算法总体流程

```
初始化种群（拉丁超立方采样）→ 真实评估
         ↓
    ┌─→ 计算 Hybrid PBI 混合分数
    │        ↓
    │   生成软排序训练对（Sigmoid 概率）
    │        ↓
    │   划分训练集/测试集（75%/25%）
    │        ↓
    │   数据归一化 + 训练神经网络
    │        ↓
    │   代理辅助选择（迭代 GA + 神经网络筛选）
    │        ↓
    │   真实评估候选解 → 更新归档集
    │        ↓
    │   环境选择（RSEA 雷达网格策略）
    │        ↓
    └── 评估次数用完？→ 否 → 回到循环起点
              ↓ 是
         输出最终结果
```

### 3.2 Hybrid PBI 混合评分

`HybridPBI_Classification` 是整个算法的评分核心，它结合两种信号生成连续分数：

**信号一：基于参考向量的 PBI 连续分数（score_v）**

```
score_v = 1 / (1 + max(d1 + θ·d2, 0))
```

其中：
- `d1` = 解沿参考向量方向的投影距离（越小越靠近理想点）
- `d2` = 解垂直于参考向量方向的偏离距离（越小越贴近参考方向）
- `θ` = 惩罚系数（默认 5），控制对偏离方向的容忍度

低维问题（M ≤ 3）使用均匀 ILD 参考向量；高维问题使用基于 k-means 的自适应参考向量。

**信号二：基于参考点的动态 PBI 标签（label_dyn）**

通过 `GetOutput_PBI` 函数，使用二分查找自动调整 delta 参数，使"好解"比例维持在 30%-70% 之间。判断标准为 PBI 聚合值是否超出参考点范围。

**混合公式：**

```
score_hybrid = (1 - ratio) × score_v + ratio × label_dyn
```

其中 `ratio = 当前评估次数 / 最大评估次数`，从 0 到 1 递增：
- **早期（ratio 小）**：更信任参考向量的连续分数，偏向全局探索
- **后期（ratio 大）**：更信任参考点的硬标签，偏向局部收敛

### 3.3 软排序对生成（核心创新）

`GetSoftRelationPairsFromScore` 是 TrueSR 的核心创新点，它将连续分数转化为软排序训练对：

**步骤一：分数归一化**
```matlab
Score = (Score - min(Score)) / (max(Score) - min(Score))
```

**步骤二：生成所有 (i, j) 配对（i ≠ j）**

**步骤三：Sigmoid 软概率计算**
```
P(i 比 j 好) = 1 / (1 + exp(-α × (score_i - score_j)))
```

其中 α = 6（默认值），控制 Sigmoid 函数的陡峭程度：
- α 越大 → 输出越接近 0/1 → 趋近硬标签
- α 越小 → 输出越接近 0.5 → 标签越"软"

**关键优势：** 当两个解分数接近时，概率接近 0.5（表示"差不多"），而非强行分 0/1。这能：
1. 保留中间解的排序信息
2. 减少边界样本对模型的误导
3. 让神经网络学习到更平滑的梯度

**步骤四：随机采样控制数量**
如果配对数超过 `pairMax`（默认 12000），随机采样以控制训练时间。

**步骤五：特征拼接**
每行输入为 `[解i的特征, 解j的特征]`，输出为概率值 P。

### 3.4 神经网络训练

**网络架构：**
```
输入层 (2D维)
    ↓
隐藏层1: ceil(1.5 × 2D) 个神经元（特征提取）
    ↓
隐藏层2: 2D 个神经元（瓶颈层）
    ↓
隐藏层3: ceil(2D / 2) 个神经元（压缩层）
    ↓
输出层: 1 个神经元（logsig 激活，输出概率 ∈ (0,1)）
```

**训练配置：**
- 训练算法：`trainscg`（缩放共轭梯度法），收敛快，适合小批量数据
- 损失函数：`mse`（均方误差），对概率值做回归
- 数据划分：`dividetrain`（所有数据用于训练，已手动划分 75%/25%）
- 输入归一化：`mapminmax` 缩放到 [-1, 1]，加速训练并提高数值稳定性

### 3.5 代理辅助选择（全分布锚点 + 正反向对称）

`RSurrogateAssistedSelection_TrueSR` 使用训练好的神经网络迭代筛选候选解：

**步骤一：生成初始候选解**
使用遗传算子（模拟二进制交叉 + 多项式变异）从当前种群和参考解生成候选解。

**步骤二：迭代筛选**
重复 wmax 次（默认 3000）：
1. 用神经网络对候选解打分
2. 保留得分最高的 |Ref| 个解作为父代
3. 用遗传算子生成新候选解

**步骤三：全分布锚点评分（关键创新）**

旧版只与最优 K 个锚点比较，TrueSR 改为从排序分布中均匀采样 `anchorNum`（默认 20）个锚点：
```matlab
anchorRank = unique(round(linspace(1, N, anchorNum)));
anchors = modelX(rankIndex(anchorRank), :);
```

锚点覆盖从最好到最差的整个分数范围，使候选解评分更接近整体排序位置。

**步骤四：正反向对称化**

对每个候选解与每个锚点，同时计算：
- 正向对：`P(候选解 比 锚点好)`
- 反向对：`P(锚点 比 候选解好)`

综合分数：
```
pairScore = 0.5 × (probForward + 1 - probReverse)
```

这种对称化处理缓解了神经网络预测不对称的问题，确保评分的公平性。

**步骤五：最终输出**
从最后一批候选解中选出分数最高的前 4 个，交给真实评估。

### 3.6 环境选择（RSEA 雷达网格策略）

`RefSelect` 使用 RSEA（Radar-grid based Selection in Environmental selection Algorithm）策略从归档集中选择 N 个代表解：

1. **非支配排序**：选出前 k 个前沿层的解
2. **目标值归一化**：消除各目标的尺度差异
3. **极值解保留**：在各目标方向上表现最优的解优先选中
4. **雷达网格映射**：将多维目标向量投影到二维极坐标，划分网格
5. **增量选择**：优先从稀疏网格中选解，同时偏向收敛性好的解

这种策略兼顾了收敛性（靠近真实 Pareto 前沿）和多样性（在前沿上均匀分布）。

## 4. 算法参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `k` | 6 | 参考解数量（用于 PBI 分类） |
| `gmax` | 3000 | 每代代理辅助搜索的最大尝试次数 |
| `pairMax` | 12000 | 训练配对的最大数量 |
| `alphaSoft` | 6 | Sigmoid 函数的陡峭系数 |
| `anchorNum` | 20 | 模型选择时的锚点数量 |

**种群大小 N：**
- D ≤ 10 时：N = 11D - 1
- D > 10 时：N = 100

## 5. 与前代算法的关键差异

| 特性 | REMO_new2 | REMO_new2_SR | REMO_new2_TrueSR |
|------|-----------|--------------|------------------|
| 训练标签 | 硬分类（好/坏 0/1） | 软标签但配对来自硬分类 | 真实软排序（连续概率） |
| 配对来源 | Catalog 好/坏类 | Catalog 好/坏类 | 全排序分数，所有 (i,j) 对 |
| 中间解处理 | 被归为坏类 | 被归为坏类 | 保留其排序位置信息 |
| 网络类型 | patternnet 三分类 | feedforwardnet 概率回归 | feedforwardnet 概率回归 |
| 锚点选择 | 最优 K 个 | 最优 K 个 | 全分布均匀采样 |
| 评分对称性 | 无 | 无 | 正反向对称化 |
| 输入归一化 | 有 | 无 | 有（mapminmax） |

## 6. 预期效果

### 6.1 更充分利用排序信息

旧方法只关心解是否属于好/坏类。TrueSR 使用连续分数差值，能表达：
- 明显的优劣关系（分数差大 → 概率接近 0 或 1）
- 接近解之间的不确定关系（分数差小 → 概率接近 0.5）
- 中间解的相对位置信息

### 6.2 减少边界噪声

硬分类中，排序第 25 名和第 26 名可能被强行分到不同类别，但二者真实质量可能非常接近。TrueSR 中如果二者分数接近，则 P ≈ 0.5，不会产生误导。

### 6.3 改善探索-利用平衡

全分布锚点使候选解不再只和精英解比较，而是放到整体排序背景中评估。这有利于区分：
- 明显优于低分解但不一定超过最优解的潜力解
- 只在局部看起来好但全局排序不稳定的解
- 与已有精英过近、探索价值有限的解

### 6.4 更符合昂贵优化目标

代理模型的目的是把有限真实评价预算分配给更有潜力的候选解。TrueSR 的输出是候选解在关系比较中的平均胜率，更直接服务于"筛选"而不是"拟合目标函数"。

## 7. 可能风险与注意事项

### 7.1 软标签依赖 score_hybrid 质量

TrueSR 并没有改变 hybrid PBI score 本身。如果某些问题上该分数与真实 Pareto 质量不一致，软排序会继承这种偏差。

### 7.2 alphaSoft 参数敏感性

α 越大，标签越接近硬标签；α 越小，标签越接近 0.5（信息量不足）。建议测试 α = {3, 6, 10}。

### 7.3 训练时间增加

pairwise 样本数为 O(N²)。当 N=100 时全配对约 9900 对，在可接受范围内。更大种群需通过 `pairMax` 控制。

### 7.4 MSE 损失函数的局限

当前使用 MSE 做概率回归，而非 RankNet 原始的交叉熵损失。MSE 对概率输出的梯度在极端值处较弱，可能影响训练效果。后续可考虑自定义交叉熵损失。

## 8. 与已有文献的关系

### 8.1 REMO（2022, IEEE TEVC）

Hao 等人提出 REMO，证明了在昂贵多目标优化中用关系学习代替直接目标回归的有效性。TrueSR 延续了 REMO 的关系学习框架，但将离散关系标签推广为连续概率关系。

### 8.2 PC-SAEA（Swarm and Evolutionary Computation）

Tian 等人提出 pairwise comparison surrogate，使用两个解的拼接向量作为代理模型输入。TrueSR 采用相同的输入格式，但使用 soft probability label 而非 hard pairwise label。

### 8.3 RankNet（2005, ICML）

Burges 等人提出用 Sigmoid 概率建模 pairwise ranking：`P_ij = sigmoid(o_i - o_j)`。TrueSR 的软概率生成公式与之一致，但训练目标来自已有 hybrid PBI 分数而非模型输出差。

### 8.4 CSEA（2018, IEEE TEVC）

Pan 等人的 CSEA 是 classification-based SAEA 的代表。TrueSR 可看作从分类代理向 learning-to-rank 代理的过渡。

## 11. 后续改进方向

1. **损失函数改进**：用 RankNet-style 交叉熵损失替代 MSE
2. **自适应 α**：早期用较小 α（更软），后期用较大 α（更硬）
3. **模型可靠性判断**：基于验证集排序准确率决定是否信任模型
4. **不确定性感知**：引入集成模型或 MC Dropout 估计预测不确定性
