# 组会汇报：REMO 目标降维实验总结

> 2026-07-01 | 超多目标优化方向

---

## 一、研究动机

**核心问题**：原始 REMO 在超多目标（M ≥ 10）场景下性能退化。

**原因分析**：关系模型在 2×M 维配对空间中学习，M 增大时输入维度高、样本稀疏、神经网络难学习。

**研究假设**：将 M 个目标聚类降维到 k_red 个聚合目标，降低代理模型学习难度，可能提升超多目标表现。

**验证逻辑**：
```
随机降维有效？ → 说明"降维本身"就够了
结构降维更优？ → 说明"如何降维"也很重要
两者都无效？   → 说明仅改代理空间不够，需要配套其他改进
```

---

## 二、实验总体架构

共两组实验，控制变量逐层推进：

```
实验组一（丰富框架）：基于 REMO_DiRel_LKC 骨架，验证降维有效性
  ├── REMO_DR_RandFixed    随机固定降维 + 双网络 + full-first仲裁
  ├── REMO_DR_LKCFixed     LKC结构降维(锁定) + 双网络 + full-first仲裁
  └── REMO_DR_LKCDynamic   LKC结构降维(动态) + 双网络 + full-first仲裁

实验组二（最小框架）：基于原始 REMO 骨架，仅替换 PBI 输入
  ├── REMO_RandRed         随机降维 + 单网络（最小改动）
  ├── REMO_SpCorrRed       Spearman聚类降维 + 单网络（最小改动）
  └── REMO_LKCRed          LKC结构降维(每4代更新) + 单网络（最小改动）
```

**两组的关系**：实验组一验证"在有丰富组件（集成、仲裁、双网络）的框架下降维是否有效"；实验组二验证"在最简单框架下（与REMO仅差两行代码）降维是否有效"。如果组二有效，说明降维的收益是独立且鲁棒的。

## 三、实验组一：DR 消融实验

### 3.1 框架来源

基于 `REMO_DiRel_LKC`，移除难度感知模块（`DifficultyProfiler`、`BuildStructureAwareEasySet`），仅保留：
- 全目标关系网络 net_F + 子目标关系网络 net_S
- Bagging 集成训练（K_ens=3）
- Full-first 仲裁选择（net_F 主导，net_S tie-break）

**唯一变量**：子目标空间的构造方式。

### 3.2 三个算法的差异

| 算法 | 分组来源 | 分组更新 | 回答的问题 |
|------|---------|---------|-----------|
| `REMO_DR_RandFixed` | `randperm` 随机均衡分配 | 初始化固定 | "随便降维"是否有效？ |
| `REMO_DR_LKCFixed` | LKC局部斜率特征+Pearson相似度+correlation k-means | warm-up后锁定 | "结构感知分组"是否有效？ |
| `REMO_DR_LKCDynamic` | 同上 | 每代重新估计 | "动态更新"是否带来额外收益？ |

### 3.3 核心代码差异

**随机分组（RandFixed）**：

```matlab
% DR_BuildRandomReduction.m
perm = randperm(M);
Groups = cell(1, k_eff);
for i = 1:M
    g = mod(i - 1, k_eff) + 1;
    Groups{g}(end+1) = perm(i);   % 轮流分配
end
% 组内等权重聚合
AggregatedObj(:, g) = F(:, C) * (ones(1,|C|) ./ |C|)';
```

**LKC结构分组（LKCFixed / LKCDynamic）**：

```matlab
% DR_BuildLKCReduction.m 核心三步
% ① 计算 LMVT 局部斜率特征 Gamma (M × nCells*D)
[Gamma, PairIndex, PairQuality] = buildGammaLMVT(X, F, nCells, epsDx);
% ② Pearson 结构相似度矩阵
Sim = pearsonRows(Gamma);
% ③ Correlation k-means 聚类
Z = normalizeRows(centerRows(Gamma));
labels = kmeansCorrelation(Z, k_eff, maxIter, repeats);
% ④ 组内加权聚合（权重 ∝ exp(-distance_to_center)）
w = exp(-dist) ./ sum(exp(-dist));
```

**LKCFixed vs LKCDynamic 差异**（在 `DR_RunMain.m` 中）：

```matlab
case 'lkcfixed'
    if gen <= lockGen  % 前 lockGen 代：用 LKC 估计结构
        State = DR_BuildLKCReduction(Input, PopObj, kRed, cfg);
        if gen >= lockGen
            State.IsFixed = true;   % 锁定分组
        end
    else               % 后续代数：直接 apply 锁定的分组
        [ReducedObj, State] = DR_ApplyReduction(PopObj, State);
    end

case 'lkcdynamic'
    State = DR_BuildLKCReduction(Input, PopObj, kRed, cfg);  % 每代重新估计
    ReducedObj = State.AggregatedObj;
```

### 3.4 双网络训练与仲裁机制

**双网络**（`DR_TrainDualScaleNet.m`）：

```matlab
% net_F：全目标关系网络（M个目标），训练60 epochs
nets_F = trainBagEnsemble(TrainIn_F_nor, TrainOut_F_oh, xDim_F, K_ens, [], 60);
% net_S：子目标关系网络（k_red个聚合目标），用 net_F 权重迁移初始化，训练30 epochs
nets_S = trainBagEnsemble(TrainIn_S_nor, TrainOut_S_oh, xDim_S, K_ens, nets_F, 30);
```

**Full-first 仲裁**（`DR_ArbitratorScore.m` 核心公式）：

```matlab
scores = baseFull                          % net_F 主导评分 (2 + 2*tanh(μ_F))
       + tieW × triggerSub × subPreference  % net_S tie-break (仅当 net_F 不确定时)
       - beta × uncertaintyPenalty          % 惩罚高不确定性
       - lambda × disagreement              % 惩罚两网络意见冲突
       + gamma × novelty;                   % 奖励远离已知样本的解
```

### 3.5 参数

```matlab
k_red=3  tau_conf=0.3  k_ref=6  gmax=1000  K_ens=3  nCells=5  scalarGap=0.05  lockGen=3
```

## 四、实验组二：最小改动降维实验

### 4.1 设计理念

**只做最小改动**：在原始 REMO 中仅替换 PBI 分类的输入，其余代码完全不动。

```
原始 REMO:  Catalog = GetOutput_PBI(PopObj(M维), RefObj(M维))
新算法:     Catalog = GetOutput_PBI(PopObj_red(k_red维), RefObj_red(k_red维))
```

相比实验组一，组二不引入任何额外组件（无集成、无双网络、无仲裁），回答更干净的问题：**降维本身（单网络+原始REMO框架）是否有效？**

### 4.2 两个算法的差异

| 算法 | 分组来源 | 方法 |
|------|---------|------|
| `REMO_RandRed` | `randperm` + 轮流分配 | `buildRandomGroups(M, k_red)` |
| `REMO_SpCorrRed` | Spearman秩相关 + 层次聚类(average linkage) | `spearCluster(PopObj, k_red)` |

### 4.3 核心代码差异

**随机分组**：

```matlab
function Groups = buildRandomGroups(M, k_red)
    perm_idx = randperm(M);
    Groups = cell(1, k_red);
    for i = 1:M
        g = mod(i - 1, k_red) + 1;
        Groups{g}(end + 1) = perm_idx(i);
    end
end
```

**Spearman聚类**：

```matlab
function Groups = spearCluster(PopObj, k_red)
    rho = corr(PopObj, 'type', 'Spearman');    % Spearman秩相关 M×M
    rho(isnan(rho)) = 0;
    D = 1 - abs(rho);                           % 距离：高度相关→小距离
    D(1:M+1:end) = 0;
    Z = linkage(squareform(D), 'average');       % 层次聚类（组平均连接）
    labels = cluster(Z, 'maxclust', k_red);      % 切分k_red组
    % 构建Groups...
end
```

**组内聚合（两算法共用）**：

```matlab
function ReducedObj = applyReduction(PopObj, Groups)
    % Step 1: 逐列 min-max 归一化到 [0,1]
    F(:,d) = (col - min(col)) ./ (max(col) - min(col));
    % Step 2: 组内等权重平均
    ReducedObj(:,g) = mean(F(:, Groups{g}), 2);
end
```

### 4.4 REMO_LKCRed — LKC 动态降维（每4代更新）

在 REMO_RandRed 和 REMO_SpCorrRed 的"初始化固定分组"基础上，增加一个**动态更新**变体：基于 LKC 局部斜率特征的动态降维，每 4 代重新聚类。

**为什么需要动态更新？**
- 固定分组只基于初始种群，初始种群来自拉丁超立方采样，分布均匀但可能不代表收敛后的 Pareto 前沿结构
- 随着进化推进，种群逐渐收敛到前沿，目标间关系可能变得更清晰（或变化）
- 动态更新用最新种群重新估计目标结构，分组可能更准确

**为什么是每 4 代？**
- 每代更新 → 子目标语义频繁跳变，标签不稳定（LKCDynamic 的风险）
- 锁定不变 → 丢失进化后期的结构信息（RandFixed/LKCFixed 的局限）
- 每 4 代折中：既让分组适应搜索阶段变化，又保持足够的稳定窗口

**核心代码**：

```matlab
% REMO_LKCRed.m 主循环中的动态更新逻辑
gen = 0;
while Algorithm.NotTerminated(Archive)
    gen = gen + 1;
    % ★ 每 updateFreq(4) 代重新 LKC 聚类（跳过第1代，已初始化）
    if gen > 1 && mod(gen - 1, updateFreq) == 0
        Groups = lkcCluster(Population.decs, Population.objs, k_red, nCells, epsDx);
    end
    % ... 其余与 REMO 完全一致
end
```

**LKC 聚类流程**（`lkcCluster` 函数）：

```matlab
% Step 1: 归一化解和目标值
[X, ~, ~] = safeMinMax(PopDec);
[F, ~, ~] = safeMinMax(PopObj);

% Step 2: 构建 LMVT 局部斜率特征 Gamma(M × nCells*D)
%   - 在决策空间划分 nCells 个网格
%   - 每格内选一对端点解，估计每个目标的局部斜率 = Δf/Δx
Gamma = buildGammaLMVT(X, F, nCells, epsDx);

% Step 3: Gamma 行中心化 → 归一化 → correlation k-means 聚类
Z = normalizeRows(centerRows(Gamma));
labels = kmeansCorrelation(Z, k_eff, 60, 8);
Groups = labelsToGroups(labels, k_eff);

% Step 4: 若特征不足（如 Gamma 全零）→ fallback 顺序均衡分组
% Step 5: 组内 min-max 归一化 + 等权重平均（与 RandRed/SpCorrRed 一致）
```

### 4.5 三种方案差异总结

|      | REMO_RandRed | REMO_SpCorrRed | REMO_LKCRed |
|------|-------------|---------------|-------------|
| **分组来源** | `randperm` + 轮流分配 | Spearman秩相关 + 层次聚类 | LMVT局部斜率 + Pearson + k-means |
| **更新频率** | 初始化固定 | 初始化固定 | 每 4 代更新 |
| **组内聚合** | min-max归一化 + 等权平均 | min-max归一化 + 等权平均 | min-max归一化 + 等权平均 |
| **新增参数** | `k_red` | `k_red` | `k_red`, `updateFreq` |
| **聚类复杂度** | O(M) | O(N×M² + M² log M) | O(N×D×nCells×M + M²×D) |

**共同框架**（与原REMO差异仅两处）：

```
★ 差异1: 参数新增 k_red, (updateFreq for LKCRed)
★ 差异2: GetOutput_PBI 输入改为降维后的目标
★ 差异3 (仅 LKCRed): 主循环中每 updateFreq 代重新聚类

初始化 → Latin Hypercube → 真实评估 → ★buildGroups
  ↓
主循环:
  ★ (仅 LKCRed) 每4代重新聚类
  RefSelect(Pop, k)               ← 原M维，不变
  ★ applyReduction → k_red维
  ★ Catalog = GetOutput_PBI(k_red维)
  GetRelationPairs                 ← 不变
  DataProcess → patternnet         ← 不变
  RSurrogateAssistedSelection      ← 不变
  真实评估                          ← 不变
  RefSelect(Archive, N)            ← 原M维，不变
```

### 4.6 参数

```matlab
REMO_RandRed:   k_red=3  k=6  gmax=3000
REMO_SpCorrRed: k_red=3  k=6  gmax=3000
REMO_LKCRed:    k_red=3  updateFreq=4  k=6  gmax=3000
```

## 七、预期与风险

### 预期现象

```
最理想:   SpCorrRed/LKCFixed > RandRed/RandFixed > REMO
          → 降维有效，且结构感知更好

部分:     RandRed > REMO 但 SpCorrRed ≈ RandRed
          → 降维有效但聚类方式不重要

有趣:     SpCorrRed > REMO 但 RandRed ≤ REMO
          → 只有基于结构的降维有用

负结果:   全部不如REMO
          → 单靠降维不够，需配套其他改进
```

### 主要风险

1. **Spearman/LKC 估计不稳**：初始样本仅 N≈100，M=15 时相关矩阵可能不可靠
2. **组内冲突抹平**：聚合丢失组内 trade-off 信息
3. **RandRed 方差大**：随机分组质量影响单次结果，需要多次运行取均值
