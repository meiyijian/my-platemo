# MiniMaSAEA: first-layer comparison

One PlatEMO algorithm, four parameter modes: `PBI`, `TCH`, `SDE`, and `OBJ`.
`PBI` is the default. Use the algorithm parameter to select a mode; the
algorithm class, candidate generator, DACE GP settings, and one-point
prediction-based prescreening remain the same.

| Mode | GP training target | Candidate score minimized |
| --- | --- | --- |
| PBI | PBI of normalized observed objectives | Predicted scalar PBI |
| TCH | TCH of normalized observed objectives | Predicted scalar TCH |
| SDE | Shift-based density score of normalized observed objectives | Predicted scalar SDE |
| OBJ | One GP per normalized objective | PBI of predicted objective vector |

The `OBJ` mode is a per-objective modeling baseline. It necessarily trains
`M` GPs, so its model count differs from the three scalar modes. It uses
the same PBI function and current reference vector at candidate selection.

All modes start from the same LHS design when MATLAB's RNG is set to the
same seed before `Solve`. Reference vectors are generated by PlatEMO's
`UniformPoint(Problem.N,Problem.M)` and sampled using a separate random
stream initialized once per run; their index sequence is therefore the
same across modes for matched seeds. Later candidate pools can differ
because previous selections change the archive.

For a matched-seed run, construct the problem, set `rng(seed)`, then call
`MiniMaSAEA('parameter',{'PBI'}).Solve(problem)`; repeat for the other
modes with the same seed. PlatEMO's `platemo(...)` entry calls
`rng('shuffle')`, so setting the seed before `platemo` does not provide
matched random streams. Its default output folder is also keyed by class
name, not the algorithm parameter: save formal results under distinct
mode-specific names or folders.

Initial evaluations are `min(11*D-1,N,floor(maxFE/2))` rather than
unconditionally `11*D-1`. For `D=30`, `N=100`, `maxFE=300`, this is 100
initial evaluations, leaving 200 for one-at-a-time infill. Candidate
generation and GP predictions do not call `Problem.Evaluation`; each infill
step calls it exactly once. The version is restricted to finite real
decision variables. Its GP uses ParEGO's DACE implementation (copied and
renamed under `private/`), first-order trend, Gaussian correlation, and
the same hyperparameter bounds in all modes. ParEGO's EI search is absent.
Before fitting, the same fixed `1e-12` normalized decision-space deduplication
is applied in every mode because DACE rejects repeated design sites.
The SDE handler uses shifted Euclidean distance to the
`floor(sqrt(archive size))`-th neighbor, then takes `1/(distance+2)` so
lower predicted scores remain preferred, following the form of PlatEMO's
`CMOEA-MS/CalSDE.m`.

This is a mechanism comparison, not a claim of final IGD/HV improvement.
No output populations are replaced or aliased across modes; record the
mode, seed, problem, budget, and source revision with every run.
