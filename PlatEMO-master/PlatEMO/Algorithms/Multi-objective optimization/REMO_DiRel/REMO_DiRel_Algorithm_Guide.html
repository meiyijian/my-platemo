📖 一、算法概述

1.1 什么是REMO_DiRel？

REMO_DiRel是REMO算法的全面升级版，专门针对超多目标优化问题（目标数M≥4）设计。它引入了三大核心创新：

🎯 三大核心创新

创新1
难度感知目标子集选择

在线评估每个目标的建模难度，选出最易建模的子集

创新2
双尺度集成网络

全目标网络+子目标网络，迁移初始化+Bagging集成

创新3
逐候选逆方差仲裁

对每个候选解，自适应融合两个模型的预测

1.2 为什么需要升级？

💡 REMO的局限性

  • 超多目标挑战：目标数增多时，关系对构造复杂度爆炸
  • 目标难度差异：有些目标容易建模，有些很难，REMO一视同仁
  • 单网络不稳定：随机初始化导致预测波动大
  • 固定融合策略：无法根据具体情况灵活调整

✅ DiRel的解决方案

  • 难度感知：自动识别并优先处理易建模的目标
  • 双尺度视角：全目标看全局，子目标看细节，互补
  • 集成学习：多个网络取平均，方差衡量不确定性
  • 逆方差仲裁：哪个模型更确定，就更信任它

🔧 三、各模块详细解析

📊
模块1：目标难度在线排序（DifficultyProfiler）核心创新

功能说明

在线评估每个优化目标的建模难度，选出最易建模的目标子集 S_easy。这是REMO_DiRel的核心创新之一。

📝 通俗解释

想象你要同时完成5门课的作业：

  • 数学：公式清晰，答案明确 → 容易
  • 物理：概念复杂，但有规律 → 中等
  • 作文：主观性强，难预测 → 困难

策略：先集中精力把容易的科目做好，再用剩余时间攻克难题。

REMO_DiRel也是这样：优先建模容易的目标，构建更准确的子目标模型。

难度计算公式

难度 = α × 建模难度 + (1-α) × 冲突难度

其中：
建模难度 = 0.5 × 目标值跨度分 + 0.5 × 改进停滞分
冲突难度 = 1 - Spearman冲突度
α = 0.6（默认权重）

滑动窗口平滑

为了使难度评估更稳定，REMO_DiRel使用滑动窗口（默认3代）对难度分数进行平滑：

% 滑动窗口平滑
col = mod(gen-1, win_K) + 1; % 循环索引：1,2,3,1,2,3,...
H.d_score(:, col) = d_now; % 存入当前代难度
d_score = meanNoNan(H.d_score, 2); % 忽略NaN求均值

好处：避免单代噪声导致的难度判断波动。

冗余检查（RefineEasySubset）

选出的易目标子集还需要进行冗余检查：

  • 如果两个目标的 |Spearman ρ| > 0.95，说明高度相关
  • 保留较易的那个，剔除较难的那个
  • 补入下一个非冗余的目标

目的：确保子集内的目标提供多样化的信息。

✅ 优点

  • 在线自适应，无需预设
  • 多维度综合评估难度
  • 滑动窗口平滑噪声
  • 冗余检查保证多样性

❌ 缺点与改进

  • 需要调参（α, win_K）
  • 计算Spearman相关有开销
  • 改进：可引入更轻量的相关度量
  • 改进：可自适应调整α权重

模块2：双尺度关系对构造（GetRelationPairsBudgeted）核心创新

功能说明

构造两种尺度的关系对：全目标关系对（看全局）和子目标关系对（看细节）。

📝 通俗解释

假设你要评价一部电影：

  • 全目标视角：综合考虑剧情、演技、特效、音乐... → 整体评价
  • 子目标视角：只看剧情和演技（最易评价的部分） → 局部评价

两种视角互补：全目标看大势，子目标看细节。

🌐 全目标关系对

输入：所有M个目标

特点：信息完整，但维度高

用途：学习全局优劣关系

维度：2M

🎯 子目标关系对

输入：k_easy个易目标

特点：维度低，建模简单

用途：学习局部精确关系

维度：2×k_easy

有上限采样

为了解决O(n²)复杂度问题，REMO_DiRel引入有上限采样：

% 关系对构造的硬上限
pairMax = 6000;

% 每类关系对最多 pairMax/3 个
perClass = max(1, floor(pairMax/3));

% 三种关系对分别采样
[XXp, Lp] = sampleCross(Input, C1, C2, perClass, 1); % +1类
[XXn, Ln] = sampleCross(Input, C2, C1, perClass, -1); % -1类
[XXz, Lz] = sampleSame(Input, C1, C2, perClass); % 0类

好处：n=100时，从9900个关系对减少到6000个，训练速度提升40%。

平衡采样策略

关系对类型 标签 采样方式 数量
+1类 正类 ≻ 负类 从C1和C2各选一个 ≤2000
-1类 负类 ≻ 正类 从C2和C1各选一个 ≤2000
0类 同类 ~ 同类 从C1或C2内部选两个 ≤2000

✅ 优点

  • 双尺度互补，信息更全面
  • 有上限采样，计算可控
  • 平衡采样，避免类别偏斜
  • 子目标维度低，训练快

❌ 缺点与改进

  • 需要预设pairMax
  • 采样可能丢失有价值的关系对
  • 改进：可引入主动学习选择最有价值的关系对
  • 改进：可自适应调整pairMax

为什么子目标网络只训练30 epochs？

  • 全目标网络从随机权重开始，需要60 epochs收敛

🔑 关键理解：为什么需要集成？

  • 单个网络：随机初始化 → 每次训练结果不同 → 不稳定
  • 集成（3个网络）：训练3个网络，取众数（投票）做预测
  • 额外收获：可以计算3个网络预测的方差，衡量不确定性

✅ 优点

  • 双尺度互补，信息更全面
  • 迁移初始化，训练更快
  • Bagging集成，预测更稳定
  • 方差可用于衡量置信度

❌ 缺点与改进

  • 需要训练6个网络（2×3）
  • 计算量较大
  • 改进：可根据问题复杂度自适应调整K_ens
  • 改进：可引入更高效的集成策略

模块4：逐候选逆方差仲裁（ArbitratorScore）核心创新

功能说明

对每个候选解，用逆方差权重自适应融合全目标网络和子目标网络的预测，并处理冲突情况。

📝 通俗解释

假设你有两个医生给你看病：

  • 全科医生（全目标网络）：看问题全面，但有时不确定
  • 专科医生（子目标网络）：专精某领域，更确定

仲裁策略：

  • 如果专科医生很确定，就听专科医生的
  • 如果全科医生很确定，就听全科医生的
  • 如果两个都很不确定，就不做决定（弃权）

逆方差权重公式

w_F(x) = (1/σ²_F(x)) / (1/σ²_F(x) + 1/σ²_S(x))

其中：
σ²_F(x) = 全目标网络对候选解x的预测方差
σ²_S(x) = 子目标网络对候选解x的预测方差

含义：方差越小 → 1/σ²越大 → 权重越大

冲突分支处理

⚠️ 当两个模型预测方向相反时

这种情况称为"冲突"，需要特殊处理：

冲突情况 条件 处理策略 理由
弃权 两模型都不确定 得分设为0 无法判断，不做决定
子目标主导 子目标确定，全目标不确定 加多样性奖励 信任确定的模型，鼓励探索

🎯 多样性奖励机制

当子目标模型主导冲突时，会计算候选解之间的新颖度：

% 计算候选解之间的欧氏距离矩阵
D_pairs = pdist2(Candidates, Candidates);

% novelty = 到最近邻居的距离
novelty = min(D_pairs, [], 2);

% 加多样性奖励
base(subwin) = base(subwin) + 0.5 .* novelty(subwin);

含义：距离其他候选解越远的解，新颖度越高，得分加成越大。这鼓励算法探索稀缺区域。

✅ 优点

  • 自适应融合，无需预设权重
  • 逐候选独立计算，灵活
  • 冲突处理策略明确
  • 多样性奖励促进探索

❌ 缺点与改进

  • 计算开销较大（需计算所有候选解的方差）
  • τ_conf需要调参
  • 改进：可引入更高效的方差估计方法
  • 改进：可自适应调整τ_conf

模块5：难度感知GA参数（difficultyAwareGAParam）核心创新

功能说明

根据易目标子集的平均难度，自适应调整遗传算法的参数。

📝 通俗解释

想象你在开车：

  • 路况好（易目标，难度低）：可以开快点，更关注前方 → 局部搜索
  • 路况差（难目标，难度高）：需要开慢点，多观察周围 → 全局搜索

参数调整策略

参数 含义 难度低时 难度高时
disC SBX分布指数 大（30）→ 子代靠近父代 小（10）→ 子代远离父代
disM 变异分布指数 大（25）→ 变异幅度小 小（5）→ 变异幅度大
proM 变异概率 小（1）→ 变异少 大（1.5）→ 变异多

🔑 核心思想

难度低 → 优化进展顺利 → 更局部搜索（exploit）

难度高 → 优化陷入困境 → 更全局搜索（explore）

这种自适应策略使算法能够根据当前状态智能调整搜索行为。

✅ 优点

  • 自适应调整，无需手动调参
  • 根据难度智能切换搜索策略
  • 平衡探索与开发

❌ 缺点与改进

  • 参数调整范围是经验值
  • 可能不够精细
  • 改进：可引入更复杂的自适应策略
  • 改进：可结合强化学习调参

💡 与REMO的区别

  • REMO：使用固定的GA参数和单一的评分模型
  • DiRel：使用难度感知GA参数 + 双尺度仲裁评分

这使得DiRel在生成候选解和筛选候选解两个环节都更加智能。

📈 六、优缺点总结

✅ REMO_DiRel的优点

  • 难度感知：智能识别并优先处理易目标
  • 双尺度互补：全目标看全局，子目标看细节
  • 集成学习：预测更稳定，方差可衡量不确定性
  • 逆方差仲裁：自适应融合，无需预设权重
  • 冲突处理：弃权+多样性奖励，策略明确
  • 难度感知GA：自适应调整搜索策略
  • 有上限采样：计算复杂度可控

❌ REMO_DiRel的缺点

  • 计算开销大：需要训练6个网络
  • 参数较多：k_easy, tau_conf, alpha, K_ens, win_K
  • 实现复杂：比REMO复杂很多
  • 低维问题：可能overkill
  • 内存占用：需要存储多个网络

🚀 七、未来改进方向

💡 方向1：自适应集成规模

现状：固定训练3个网络

改进：根据问题复杂度和样本量动态调整K_ens

好处：简单问题用更少网络，节省计算

💡 方向2：主动学习选择关系对

现状：随机采样关系对

改进：选择最有信息量的关系对进行训练

好处：用更少的关系对达到更好的效果

💡 方向3：自适应阈值调整

现状：τ_conf=0.3是固定值

改进：根据预测准确率动态调整

好处：更灵活的冲突处理

💡 方向4：引入元学习

现状：每次从零开始学习

改进：利用历史任务的经验加速学习

好处：减少训练次数，提高效率
