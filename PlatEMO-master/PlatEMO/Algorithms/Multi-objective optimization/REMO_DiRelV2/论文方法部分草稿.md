# Difficulty-aware Relation Modeling for Expensive Many-objective Optimization

## 摘要 (Method Section Lead-in)

We propose **D-REMO**, a difficulty-aware relation modeling framework for expensive many-objective optimization. Unlike prior REMO-style methods that train a single relation network on the full objective space, D-REMO maintains a bank of relation experts on *difficulty-aware sub-objective subsets*, learns from *true pairwise subset Pareto + PBI labels*, and selects candidates by a *reliability-calibrated acquisition* that combines expected-win, ensemble uncertainty, archive-aware novelty, and full-vs-subset disagreement penalty.

## 3.1 Objective-wise Difficulty Estimator

We characterize each objective $f_j$ ($j=1,\dots,M$) by a 5-component difficulty score:

$$
D_j = w_{\text{prog}} D^{\text{prog}}_j + w_{\text{learn}} D^{\text{learn}}_j + w_{\text{conf}} D^{\text{conf}}_j + w_{\text{sens}} D^{\text{sens}}_j + w_{\text{span}} D^{\text{span}}_j.
$$

Default weights: $w_{\text{prog}}=0.35,\ w_{\text{learn}}=0.25,\ w_{\text{conf}}=0.20,\ w_{\text{sens}}=0.15,\ w_{\text{span}}=0.05$.

- **$D^{\text{prog}}_j$ progress stagnation.** Using the archive $\mathcal{A}$, let $q_j^{10}(t) = $ 10-th percentile of $\{f_j(x): x\in\mathcal{A}\}$ at generation $t$. The relative improvement
  $\text{relImp}_j = \max\!\left(0, \frac{q_j^{10}(t-1)-q_j^{10}(t)}{|q_j^{10}(t-1)|+\varepsilon}\right)$
  is min-max normalized across $j$, and $D^{\text{prog}}_j = 1-\widetilde{\text{relImp}}_j$.

- **$D^{\text{learn}}_j$ learnability.** $K$-fold Kriging NRMSE on a random sub-archive (default $|\mathcal{A}|=60$). Run every $G_{\text{krig}}=3$ generations to amortize cost; intermediate generations reuse the last value.

- **$D^{\text{conf}}_j$ conflict.** Crucially we use only the *negative* Spearman correlation: $D^{\text{conf}}_j = \frac{1}{M-1}\sum_{k\neq j} \max(0,-\rho_{jk})$, then min-max normalize. This avoids the common pitfall of treating strongly negatively correlated objectives as redundant.

- **$D^{\text{sens}}_j$ relation sensitivity.** On 300 random pairs, compute the Pareto label $y^{\text{full}}_p \in \{+1,0,-1\}$ on the full objective space and $y^{(-j)}_p$ on the leave-one-out space. $D^{\text{sens}}_j = \Pr[y^{\text{full}} \neq y^{(-j)}]$, normalized.

- **$D^{\text{span}}_j$ robust span.** Normalized $\log(1+q^{90}_j - q^{10}_j)$. Small weight to avoid scale-driven bias.

We apply EMA smoothing $D_j(t) = \alpha D_j^{\text{raw}}(t) + (1-\alpha) D_j(t-1)$ with $\alpha=0.5$ to suppress single-generation noise.

## 3.2 Multi-scale Sub-objective Subsets

Given $D \in \mathbb{R}^M$ sorted ascending (easiest first), we define $K$ nested subsets:

- $M \geq 5$: $S_1 = $ easiest $\lceil M/3 \rceil$, $S_2 = $ easiest $\lceil 2M/3 \rceil$, $S_{\text{full}} = \{1,\dots,M\}$.
- $M \in \{3,4\}$: $S_1 = $ easiest $\lceil M/2 \rceil$, $S_{\text{full}}$.
- $M = 2$: $S_{\text{full}}$ only.

For each non-full subset, we apply a strong-positive-redundancy filter: if $\exists\ a,b \in S$ with $\rho_{ab} > 0.95$, drop the one with higher $D_j$ and add the next-easiest non-redundant objective from outside $S$. **Strong negative correlation ($\rho_{ab}<-0.95$) is preserved as informative complementarity.** $S_{\text{full}}$ is never filtered.

## 3.3 Pairwise Pareto–PBI Labeling

For each subset $S_k$ and pair $(x_a, x_b)$:

1. **Pareto on $S_k$.** If $f_{S_k}(x_a) \preceq f_{S_k}(x_b)$ and at least one component strictly smaller, set $y_{ab,k}=+1$; symmetric for $b$ dominating $a$.
2. **PBI fallback** for nondominated pairs. With $V_k$ a set of reference vectors and $\theta=5$, compute the scalarizing value
   $g_{\text{PBI}}(f \mid v) = d_1 + \theta d_2$,
   where $d_1$ is the projection of $f$ on $v$ and $d_2$ the perpendicular distance. Define $g_k(x) = \min_{v\in V_k} g_{\text{PBI}}(\tilde{f}_{S_k}(x) \mid v)$ where $\tilde f$ is q10/q90-normalized. The relative margin is
   $\delta_{ab,k} = (g_k(x_b)-g_k(x_a))/\max(|g_k(x_a)|, |g_k(x_b)|)$.
3. **Tie handling.** If $|\delta_{ab,k}| < \tau_{\text{tie}}$ (default $10^{-3}$) the label is 0; otherwise $\pm 1$ by sign. We attach a per-pair weight $w_{ab,k} = \min(1, |\delta_{ab,k}|/(5\tau_{\text{tie}}))$ clipped at 0.1.

A budget of $B_{\text{pair}}=4000$ pairs per expert is enforced with balanced sampling across $\{+1,0,-1\}$.

**Key property.** The same pair can receive different labels under different $S_k$, which is the source of multi-scale signal.

## 3.4 Relation Expert Bank

For each PairBank we train an independent relation expert via bagged neural ensemble ($K_{\text{ens}}=5$):

- Pair feature: decision-variable concatenation $[x_a, x_b] \in \mathbb{R}^{2D}$.
- Architecture: single hidden layer of size $h = \mathrm{clip}(\lfloor D \rfloor, 8, 24)$, softmax over $\{+1,0,-1\}$. Hidden size is forced scalar to avoid a common patternnet pitfall where vector-valued $h$ is mis-parsed as multi-layer.
- Each member uses 70% bagging and stratified 75/25 train/val split. Sample weights from §3.3 enter MSE.
- Transfer initialization: when input dimensions match (i.e. between full and full-sized $S$), initialize sub-objective experts with full-expert weights.

Each expert reports validation 0/1 error $\epsilon_e$ and Brier score, which feed the acquisition.

## 3.5 Reliability-calibrated Candidate Acquisition

For a candidate $x$ and a set of *individual-level* anchors $\mathcal{A}_{\text{anc}} = \mathcal{A}_{\text{elite}} \cup \mathcal{A}_{\text{div}}$ selected from the archive (elite = nondominated; diverse = farthest-first traversal):

- **Expected-win per expert** $R_e(x) = \frac{1}{|\mathcal{A}_{\text{anc}}|} \sum_{a\in\mathcal{A}_{\text{anc}}} w_a [\Pr(x \succ a \mid e) - \Pr(a \succ x \mid e)]$ with $w_a=1$ for elite, $0.5$ for diverse. Both directional pair-features $[x,a]$ and $[a,x]$ are averaged for symmetry.
- **Local confidence** $c_e(x) = $ mean probability margin across anchors.
- **Global reliability** $g_e = 1-\epsilon_e$.
- **Per-candidate expert weight** $\tilde w_e(x) = g_e \cdot c_e(x)$, renormalized to sum to 1. We enforce a minimum share of $0.30$ for the full expert to prevent subset-expert hijack.
- **Ensemble uncertainty** $U(x) = $ weighted average of intra-ensemble variance.
- **Archive novelty** $N(x) = $ min normalized decision-space distance to $\mathcal{A}$.
- **Full-vs-subset disagreement** $\Delta(x) = \max(0, -R_{\text{full}}(x) \cdot \bar R_{\text{sub}}(x)) \cdot c_{\text{full}}(x) \cdot \bar c_{\text{sub}}(x)$, normalized.

The final acquisition score:

$$
\mathcal{S}(x) = \sum_e \tilde w_e(x) R_e(x) + \beta U(x) + \gamma N(x) - \lambda \Delta(x),
$$

with $\beta=0.10,\ \gamma=0.15,\ \lambda=0.25$.

Top-$q$ selection adds a greedy minimum-distance constraint (0.02 to archive, 0.03 between selected) to prevent clustered batches.

## 3.6 Complexity Analysis

Per generation, dominant costs are (a) PairBank construction $O(K \cdot N^2)$ for $N<120$ or $O(K \cdot B_{\text{pair}})$ for larger $N$; (b) expert training $O(K \cdot K_{\text{ens}} \cdot \text{epochs} \cdot B_{\text{pair}})$; (c) scoring $O(K_{\text{ens}} \cdot n_{\text{cand}} \cdot |\mathcal{A}_{\text{anc}}|)$. With default settings ($K=3, K_{\text{ens}}=5, B_{\text{pair}}=4000, n_{\text{cand}}=1000, |\mathcal{A}_{\text{anc}}|=30$), per-generation surrogate cost is a few seconds on a 2024-class laptop; the true-evaluation budget ($q$ per generation) is the bottleneck.

## 3.7 Ablation Design

We validate each contribution by isolating it (see `run_ablation_DiRelV2.m`):

| Mode | Description | Tests |
|---|---|---|
| A0 | REMO baseline | overall improvement |
| A1 | REMO_DiRel V1 (Catalog labels, single easy subset) | V2 vs V1 |
| A2 | D-REMO full | reference |
| A_oldLabels | Catalog-induced labels with V2 elsewhere | true-Pareto labeling impact |
| A_singleSubset | only $S_{\text{full}}$ | multi-subset value |
| A_noNovelty | $\gamma=0$ | archive novelty value |
| A_noDisagree | $\lambda=0$ | disagreement penalty value |
| A_noFullExpert | minimum full weight = 0 | full-expert anchoring value |
| A_noTransfer | random init for sub experts | transfer init value |
| A_oldDifficulty | V1 difficulty profiler | difficulty redefinition impact |

Test problems: DTLZ1–DTLZ7, WFG1–WFG9, with $M\in\{5,8,10,15\}$. 21 runs per cell. Metrics: IGD, IGD+, HV. Statistical tests: Wilcoxon signed-rank with Holm correction; Friedman across algorithms.
