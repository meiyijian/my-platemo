# REMO 算法详细报告

## 概述

**REMO** (Relation learning for Expensive Multiobjective Optimization) 是一种面向**昂贵多目标优化问题**的代理模型辅助进化算法，发表于 *IEEE Transactions on Evolutionary Computation* (TECV) 2022 年。

**核心思想：** 不直接预测目标函数值（真实评估代价极高），而是训练一个关系预测模型来判断"两个解之间谁比谁好"，用该模型筛选有潜力的新解，从而大幅减少昂贵的真实函数评估次数。

- **论文：** H. Hao, A. Zhou, H. Qian, and H. Zhang, "Expensive multiobjective optimization by relation learning and prediction," *IEEE Trans. Evol. Comput.*, vol. 26, no. 5, pp. 1157-1170, 2022.
- **平台：** PlatEMO (MATLAB)
- **标签：** `<multi/many>` `<real>` `<expensive>`
- **默认参数：** k=6 (参考解数量), gmax=3000 (代理评估次数上限)

## 算法主流程 (`REMO.m`)

### 初始化阶段

```matlab
if Problem.D <= 10
    N = 11*Problem.D-1;   % 低维问题：种群大小随维度线性增长
else
    N = 100;               % 高维问题：固定种群大小
end
```

1. 使用 **拉丁超立方采样** (`UniformPoint(N, D, 'Latin')`) 在 [0,1] 空间均匀生成初始种群
2. 将采样点映射到问题的真实变量边界 `[lower, upper]`
3. 调用 `Problem.Evaluation` 进行**真实函数评估** —— 这是整个算法中**唯一进行真实评估的地方**（除后续代理筛选后的少量评估）
4. 所有评估过的解存入 `Archive` 存档

### 主优化循环

每轮迭代执行以下 6 个步骤：

```
┌─────────────────────────────────────────────────────────┐
│  Step 1: 选择参考解 (RefSelect)                           │
│  Step 2: PBI 分类标注 (GetOutput_PBI)                     │
│  Step 3: 构建关系对 (GetRelationPairs)                     │
│  Step 4: 划分训练/测试集 (DataProcess)                     │
│  Step 5: 训练神经网络 (patternnet)                        │
│  Step 6: 代理模型辅助选择 (RSurrogateAssistedSelection)    │
│         ↓ 真实评估新解 → 更新 Archive                      │
│         ↓ 从 Archive 重选下一代种群                         │
└─────────────────────────────────────────────────────────┘
```

**关键数据流：**

```
Population.decs (决策变量)
    │
    ├──→ GetOutput_PBI → Catalog (1/非1 分类)
    │
    └──→ GetRelationPairs → XXs (配对数据), YYs (关系标签 1/0/-1)
            │
            └──→ DataProcess → TrainIn/TrainOut, TestIn/TestOut
                    │
                    └──→ patternnet 训练 → net (神经网络)
                            │
                            └──→ RSurrogateAssistedSelection → Next (候选新解)
                                    │
                                    └──→ Problem.Evaluation → Archive
```

## 核心函数详解

### 1. `RefSelect.m` — 参考解选择

**目的：** 从当前种群中选出 k 个最具代表性的解作为参考解，代表 Pareto 前沿的不同区域。

**流程：**

1. **非支配排序** — `NDSort(PopObj, k)` 按 Pareto 支配关系分层
2. **选择前 MaxFNO 层** 作为候选集
3. **目标值归一化** 到 [0,1] 范围
4. **环境选择** (`LastSelection`)：
   - 找出**极端解**（在每个目标维度上表现最好的解），优先保留
   - 计算每个解的**收敛性**（目标值加权和，越小越好）
   - 使用 `RadarGrid` 将多目标解映射到 **2D 雷达坐标**，划分 `div×div` 网格
   - 贪心选择：适应度 = `0.1 × M × Convergence - min(与已选解的距离)`
   - 优先选：收敛性好 + 处于稀疏网格 + 远离已选解的个体

**RadarGrid 映射原理：**
- 将 M 个目标均匀分布在 [0, 2π] 角度上
- 雷达坐标：`x = Σ(fi·cos(θi)) / Σ(fi)`, `y = Σ(fi·sin(θi)) / Σ(fi)`
- 归一化到 [0,1] 后，向下取整划分网格

### 2. `GetOutput_PBI.m` — PBI 分类器

**目的：** 以参考解为基准，将每个解标注为"好"(1) 或"不好"(非1)。

**PBI 聚合函数：** `g = d1 + δ × d2`

| 分量 | 含义 | 计算方式 |
|------|------|----------|
| d1 | 解在参考方向上的投影距离 | `normP × cos(θ)` |
| d2 | 解偏离参考方向的垂直距离 | `normP × sin(θ)` |
| δ | 惩罚参数 | 自适应调整 |

**分类规则：** 归一化后 `g/||Ref-Z|| > 1` → 标记为"不好"

**自适应 δ 机制：**
- 在 [-20, 20] 范围内二分搜索
- 目标：使好解比例 r 保持在 [0.3, 0.7] 之间
- 好解太多 → 增大 δ（收紧标准）；好解太少 → 减小 δ（放宽标准）
- 收敛条件：区间宽度 < 0.1 或 r 进入目标范围

**空间划分：** 基于余弦相似度将每个解分配给最近的参考解"领地"，在各自领地内独立计算 PBI 值。

### 3. `GetRelationPairs.m` — 关系对构建

**核心思想：** 不直接预测"这个解好不好"，而是预测"解A和解B之间是什么关系"。

**四种配对类型：**

| 配对 | 含义 | 标签 | 样本量 |
|------|------|------|--------|
| C1-C1 | 好解 vs 好解 | 0 (等价) | 随机采样控制 |
| C2-C2 | 不好 vs 不好 | 0 (等价) | 随机采样控制 |
| C1-C2 | 好解 vs 不好解 | 1 (A优于B) | 全部使用 |
| C2-C1 | 不好 vs 好解 | -1 (B优于A) | 全部使用 |

**自配对消除：** C1-C1 和 C2-C2 中删除"解和自己配对"的无效样本。

**类别平衡策略：** 以 C1-C2 配对数的一半为基准 `t_num`：
- 同类配对过多 → 下采样到 `t_num`
- 某类配对不足 → 从另一类补充，保证总数 = `2 × t_num`

### 4. `DataProcess.m` — 数据划分

- **采样策略：** 分层随机采样 (Stratified Sampling)
- **比例：** 训练集 75%，测试集 25%
- **实现：** 对每种类别 (1/0/-1) 分别 `randperm` 随机抽取
- **后处理：** 训练集和测试集各自打乱顺序，避免批次效应

### 5. `onehotconv.m` — 独热编码转换

**为什么需要：** 类别标签 1/0/-1 是离散值，神经网络会误以为存在大小关系 (1 > 0 > -1)。独热编码消除这种偏见。

| 模式 | 输入 | 输出 |
|------|------|------|
| 编码 (mode=1) | [1; 0; -1] | [1,0,0; 0,1,0; 0,0,1] |
| 解码 (mode=2) | [1,0,0; 0,1,0; 0,0,1] | [1; 0; -1] |

### 6. `RSurrogateAssistedSelection.m` — 代理模型辅助选择

**目的：** 用训练好的关系模型指导遗传算法，高效生成有潜力的新解。

**流程：**

```
初始候选解 = OperatorGA(当前种群 + 参考解)
    │
    ▼
┌─────────────────────────────────┐
│  while i < gmax:                │
│    1. model_select 评分排序       │
│    2. 保留前 k 个最好的解         │
│    3. 用保留的解 + 参考解 → 再生成 │
│    4. i += 新生成数量             │
└─────────────────────────────────┘
    │
    ▼
最终筛选：分数 > 3.9 的解送往真实评估
(不足4个则取 top-4)
```

**model_select 评分机制：**

对每个候选解 Xi，构建与已知好解(C1)和差解(C2)的所有配对：

```
配对组合：(C1, Xi), (Xi, C1), (C2, Xi), (Xi, C2)
                ↓
    神经网络预测 → [P(好), P(相等), P(差)]
                ↓
    累计 Xi 的"好"得分和"差"得分
                ↓
    最终分数 = 好得分 - 差得分
```

**评分逻辑举例（C1-Xi 配对）：**
- 网络预测 "C1优于Xi" → Xi 减分（差得分+1）
- 网络预测 "Xi优于C1" 或 "相等" → Xi 加分（好得分+1）

### 7. 神经网络训练 (`REMO.m` 内)

```matlab
% 数据预处理
TrainIn_nor = mapminmax(TrainIn')'     % 归一化到 [-1, 1]
TrainOut_onehot = onehotconv(TrainOut, 1)  % 标签 → 独热编码

% 网络架构
net = patternnet([ceil(xDim*1.5), xDim*1, ceil(xDim/2)])
% 3 层隐藏层 + 3 个输出神经元（对应 3 类关系）

% 示例：决策变量维度 D=10，配对数据维度 xDim=20
% 网络结构：20 → 30 → 20 → 10 → 3
```

训练后对测试集预测，计算分类错误率 `p_err = sum(TestPre ~= TestOut) / size(TestPre, 1)`。

## 关键参数汇总

| 参数 | 默认值 | 说明 | 影响 |
|------|--------|------|------|
| `k` | 6 | 参考解数量 | 越多参考点越细，但分类开销增大 |
| `gmax` | 3000 | 代理模型评估总次数上限 | 控制搜索深度和计算资源 |
| `PBI δ` | 自适应 | 惩罚参数，二分搜索范围 [-20, 20] | 控制好解比例在 30%~70% |
| 初始种群 | 11D-1 (D≤10) 或 100 (D>10) | 拉丁超立方采样 | 低维随维度增长，高维固定 |
| 网络隐藏层 | [ceil(2D×1.5), 2D, ceil(D)] | 3 层全连接 | 例：D=10 → [30, 20, 10] |
| 训练/测试比 | 75%/25% | 分层随机采样 | 保持类别分布一致 |
| 高分阈值 | 3.9 | 模型评分筛选阈值 | 超过此值的解才送真实评估 |
| 最低筛选数 | 4 | 高分不足时的保底数量 | 保证每代至少有少量新解 |
| GA 参数 | {1, 15, 1, 5} | SBX 交叉 + 多项式变异 | 控制遗传算子强度 |

## 算法特点总结

### 核心创新

1. **关系学习代替函数逼近**
   - 传统方法：代理模型直接预测目标值（回归任务）
   - REMO：学习解之间的优劣关系（分类任务）
   - 优势：对目标函数尺度不敏感，相对排序比绝对值更易学习

2. **配对策略与对照评价**
   - 候选解与已知好解/差解配对，通过"对照"综合评分
   - 四种配对方向 (C1-Xi, Xi-C1, C2-Xi, Xi-C2) 提供互补信息

3. **模型在环的正反馈生成**
   - GA 生成 → 模型筛选 → 保留优质解 → 再生成
   - 形成迭代优化循环，逐步聚焦有潜力的搜索区域

4. **自适应 PBI 分类**
   - 二分法自动调整分类标准，适应不同问题特征
   - 避免人工调参和分类偏斜

### 局限性

1. **维度敏感性**：配对数据维度 = 2×D，高维时网络规模和配对数量呈平方增长
2. **每轮重训练**：每代都要重新训练神经网络，存在训练开销
3. **gmax 参数敏感**：取值影响搜索充分性和计算成本的平衡
4. **类别不平衡**：虽然做了平衡处理，但 C1-C2 配对数量可能远多于其他类别

---

## 适用场景

- **昂贵优化问题：** 每次真实评估代价极高（CFD 仿真、物理实验、药物分子模拟等）
- **中等维度决策变量：** D ≤ 30 较宜，过高维度会导致配对数据膨胀和网络规模过大
- **多目标/高维目标：** 适用于 2~15 个目标的优化问题
- **实数编码问题：** 决策变量为连续实数
