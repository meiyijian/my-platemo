## 零、写在前面：AI 时代的学习策略

过去你听到的"研究生要学的"，是按"信息检索成本高"的时代写的。现在 AI 把信息检索成本降到 0，**你的时间应该投在 AI 替代不了的地方**。

判断一个知识点要不要自己深学，问三个问题：

| 问题 | 答案是"是" | 答案是"否" |
|---|---|---|
| 1. 老师当面追问你时，AI 来得及帮你吗？ | → P0 必须深掌握 | 可以让 AI 帮 |
| 2. 这是你方法**机制层面**的依赖吗？（不懂就写不出 Method 章节） | → P0 / P1 | P2 / P3 |
| 3. 这个知识每天用 N 次，你每次都查会拖慢你吗？ | → P0 / P1 | P2 / P3 |

**底层原则**：
- **概念、机制、判断**：你必须深掌握（AI 不能替你形成 taste）
- **格式、代码模板、文献检索、英语润色**：让 AI 全权代劳
- **实验结果的"为什么"**：只有你能解释（AI 不知道你算法的具体实现细节）

## 二、P0 必须深度掌握（论文壁垒）

> 这一节的每个知识点，**老师当面追问时你必须 30 秒内有答案**。

### P0-1：测试集——DTLZ 系列特点（必须能讲每一题的"陷阱"）

DTLZ（Deb, Thiele, Laumanns, Zitzler）是超多目标 benchmark 的鼻祖。你必须**逐题知道它考什么**。

| 题目 | PF 形状 | 主要考察 | 你的算法在这里容易失败的点 |
|---|---|---|---|
| **DTLZ1** | 线性超平面 | 收敛性（多模态） | 多模态局部最优陷阱；M↑ 时局部最优数指数增长 |
| **DTLZ2** | 凹的单位球面 | 多样性维持（基础题） | 最简单的均匀分布题，是其他题的基线 |
| **DTLZ3** | 凹球面 + 强多模态 | DTLZ1 + DTLZ2 难度叠加 | 极难收敛，常被用来淘汰算法 |
| **DTLZ4** | 凹球面 + 偏置 | 多样性（偏置分布） | 解会聚到某一个角，多样性维持失败 |
| **DTLZ5** | **退化（degenerate）** | 高维 PF 实为低维流形 | M≥4 时真实 PF 是 1 维曲线，参考向量浪费 |
| **DTLZ6** | DTLZ5 + 强多模态 | 退化 + 收敛 | 比 DTLZ5 难得多 |
| **DTLZ7** | **断开的 disconnected** | 多样性（不连通 PF） | 你的 PIEA4 在这里崩了 62%——典型场景 |

**REMO 默认实验里 DTLZ 是必跑的**。你必须能口述 30 秒：「DTLZ1 多模态，DTLZ4 偏置，DTLZ5/6 退化，DTLZ7 不连通——这就是 DTLZ 的四大变形」。

**强制自测**：
- 打开 PlatEMO 里 `Problems/Multi-objective optimization/DTLZ/DTLZ7.m`，读懂目标函数
- 在白板上画 M=3 的 DTLZ7 真实 PF（4 段不连通）

### P0-2：测试集——WFG 系列特点

WFG (Walking Fish Group) 是 **"可调难度"** 的工具箱——它通过组合 transformation 让你能定制 bias/shape/linkage 等特性。

**WFG 的核心特征**（必须记住）：
- 决策变量分为 **position-related** 和 **distance-related**——前者控制 PF 上的位置，后者控制到 PF 的距离
- 通过 **shape function** 决定 PF 形状（linear/convex/concave/disconnected/mixed）
- 通过 **transformation** 决定难度（bias/shift/reduction）

| 题目 | 主要考察 | 难点 |
|---|---|---|
| **WFG1** | bias + flat region | 平坦区误导收敛方向 |
| **WFG2** | disconnected | 不连通 PF（5 段在 M=2，更复杂在高维） |
| **WFG3** | degenerate | 退化为低维 PF |
| **WFG4** | **多模态**（Rastrigin-like） | 强收敛挑战 |
| **WFG5** | **deceptive**（欺骗性） | 局部最优更具吸引力 |
| **WFG6** | **non-separable** | 决策变量耦合 |
| **WFG7** | bias | 容易题（适应度地形偏置） |
| **WFG8** | non-separable + bias | 高难 |
| **WFG9** | deceptive + non-separable + bias | 最难，全员阵亡 |

**和 DTLZ 的本质区别**：DTLZ 主要变 PF 形状，WFG 还变**地形**（多模态、欺骗性、不可分）。所以**WFG 通常比 DTLZ 难**，是论文里"我的算法在难题上也行"的证据。

**强制自测**：
- 能说出"WFG4 和 DTLZ3 都考多模态，但 WFG4 更工程化（Rastrigin 风格），DTLZ3 是几何叠加"
- 能解释为什么 WFG6/8 (non-separable) 对代理模型挑战大（代理学不到独立变量贡献）

### P0-3：测试集——MaF 系列特点

MaF (Many-objective Function, Cheng et al., 2017) 是**专为超多目标设计**的，是你这个方向的关键 benchmark。

| 题目 | 来源/特点 |
|---|---|
| MaF1 | 修正的 DTLZ1（线性 PF） |
| MaF2 | 修正的 DTLZ2（凹 PF） |
| MaF3 | 修正的 DTLZ4（badly scaled） |
| MaF4 | 凸 PF（DTLZ1 反） |
| MaF5 | 凸 + 偏置 |
| MaF6 | **退化** |
| MaF7 | **不连通**（类 DTLZ7） |
| MaF8 | **Polygon problem**（在二维平面上的多边形顶点目标） |
| MaF9 | 多边形 + 不规则 |
| MaF10-12 | WFG 变体 |
| MaF13 | **PF 是 3 维 manifold**（不规则） |
| MaF14 | 大规模决策变量 |
| MaF15 | 大规模 + 高维目标 |

**论文价值**：MaF 是**真正区分"超多目标算法"和"普通多目标算法"**的 benchmark。**你的论文如果不跑 MaF，审稿人会怀疑你只是改了改 DTLZ**。

### P0-4：评价指标——IGD / IGD+

**IGD (Inverted Generational Distance)**：

$$IGD(P, P^*) = \frac{1}{|P^*|} \sum_{v \in P^*} \min_{p \in P} d(v, p)$$

- $P^*$ 是**真实 PF 的采样点**
- $P$ 是算法返回的近似解集
- **解释**：真实 PF 上每个点到最近 $P$ 的距离的平均
- **越小越好**

**IGD 同时衡量收敛性和多样性**——这是它流行的原因。

**IGD+** (Ishibuchi 2015 改进版)：
- IGD 的问题：它**对支配关系不敏感**——一个被支配的点离 PF 近，IGD 反而小。
- IGD+ 只算"$v$ 比 $p$ 更优的维度上的距离"，**对支配关系敏感**。
- **超多目标场景推荐 IGD+ 而不是 IGD**。

**强制自测**：
- 能在白板上画一个 2D 例子，证明 IGD 的"误判"（被支配的解 IGD 反而小）
- 能解释 IGD+ 的修正机制

### P0-5：评价指标——HV (Hypervolume)

**HV** 是**唯一公认的 Pareto-compliant** 指标——它和 Pareto 支配关系一致。

$$HV(P, r) = \text{Volume}\left(\bigcup_{p \in P} [p, r]\right)$$

其中 $r$ 是 reference point（必须比 PF 所有点劣）。

**关键认知**：
- M=2,3 时 HV 算得快
- **M ≥ 4 计算复杂度爆炸**（指数增长）
- M ≥ 6 必须用 Monte Carlo 近似 (WFG-HV / HMS-HV)
- 论文里 M ≥ 10 不报 HV 或报 MC-HV 都可以接受

**对你的方向（M=5-20）的策略**：
- M=5, 8：报 HV（用 PlatEMO 的 HV 函数）
- M=10, 15, 20：只报 IGD+ / R2，HV 标"-"或用 MC-HV

**强制自测**：
- 知道为什么 HV 在 M=10 算不动（理论复杂度 O(N^{M-1})）
- 选择 reference point 的常见做法（比 PF nadir 大 0.1 倍 range，或者用 1.1×max）

### P0-6：评价指标——R2 / Ranking Accuracy

**R2 indicator**（Hansen & Jaszkiewicz, 1998）：
- 基于一组 utility function（通常是 Tchebycheff），衡量解集对每个 utility 的最优表现
- 计算复杂度低，可扩展到任意 M
- 在 M ≥ 10 是 HV 的替代品

**Ranking Accuracy（关系学习专属！）**：
- 这是**你方向独有**的指标
- 定义：随机抽取一对解 $(x_i, x_j)$，真实 PBI 关系（i 比 j 好 / 否），代理模型预测正确的比例
- 你的代理模型 → 论文 Method 章节里**必须报这个指标**

**强制自测**：
- 用伪代码写出 ranking accuracy 的计算（5 行内）
- 知道 R2 indicator 怎么用（PlatEMO 里 `Metrics/R2.m`）

### P0-7：Pareto 支配关系及其在超多目标下的失效

**基本支配**：$x \prec y$ 当且仅当 $\forall i: f_i(x) \leq f_i(y)$ 且 $\exists j: f_j(x) < f_j(y)$。

**超多目标下的核心痛点**：
- 当 M = 10，**两个随机解互不支配的概率 > 99%**（理论计算可推）
- 结果：**整个种群几乎全在 Rank 1**，NSGA-II 的非支配排序失去选择压力

**改进型支配**：

| 名称 | 思想 | 用在哪 |
|---|---|---|
| **ε-dominance** | 容许 ε 范围内可互相支配 | Coello 早期工作 |
| **θ-dominance** | 用 PBI 距离 + 角度判断 | θ-DEA |
| **CDAS** | 收缩支配区域角度 | Sato 2007 |
| **Fuzzy dominance** | 软化支配关系 | Köppen |
| **Strengthened dominance (SDR)** | 同时考虑收敛和分布 | NSGA-III 的 niche-preservation |

**强制自测**：
- 能解释为什么 M=10 时 Pareto 失效（用概率论简单推导）
- 知道 θ-dominance 的公式：$\theta_1, \theta_2$ 是与参考向量的角度，距离的两部分

### P0-8：PBI / Tchebycheff / Weighted Sum 分解

**这三个是 MOEA/D 和 REMO 都要用的"标量化函数"**。

**Weighted Sum (WS)**：
$$g^{ws}(x|w) = \sum_{i=1}^M w_i f_i(x)$$
- 简单，但**只能找到凸 PF 上的点**——凹 PF 大段找不到

**Tchebycheff (TCH)**：
$$g^{tch}(x|w, z^*) = \max_{1 \leq i \leq M} \{w_i |f_i(x) - z^*_i|\}$$
- 凸凹 PF 都能找
- 但**不连续，难优化**

**PBI (Penalty-based Boundary Intersection)**：
$$g^{pbi}(x|w, z^*) = d_1 + \theta \cdot d_2$$

其中：
- $d_1 = \|(f(x) - z^*)^T w\| / \|w\|$ —— 参考向量方向上的投影长度（**收敛性**）
- $d_2$ = $\|f(x) - z^* - d_1 \cdot w/\|w\|\|$ —— 到参考向量的垂直距离（**多样性**）
- $\theta$ 是惩罚系数（通常 5.0）

**REMO 的核心标签机制就是 PBI**。你必须能在白板上画出这张图：

```
       ↑  f₂
       │       ●  解 x
       │      /│
       │     / │ d₂  (垂直距离, 多样性)
       │  d₁/  │
       │   /   │
       │  /    │
       │ /     │ → 参考向量 w
       z*──────────────→ f₁
```

**强制自测**：
- 闭着眼睛画 PBI 几何图
- 写出 PBI 公式
- 能解释为什么 $\theta$ 越大越偏向"贴着参考向量走"（多样性优先）

### P0-9：APD (Angle Penalized Distance) ——RVEA 核心

**APD** 是 K-RVEA 等算法的基石，**你论文要扩展超多目标，必须懂**。

$$\text{APD}(x, w_r) = \left(1 + M \cdot \left(\frac{t}{t_{max}}\right)^\alpha \cdot \frac{\theta(x, w_r)}{\gamma_r}\right) \cdot \|f(x) - z^*\|$$

- $\theta(x, w_r)$：解 $x$ 与参考向量 $w_r$ 的夹角
- $\gamma_r$：$w_r$ 与最近邻参考向量的夹角（用于归一化）
- $\|f(x) - z^*\|$：收敛距离
- 早期 $t$ 小，惩罚轻（探索）；后期 $t$ 大，惩罚重（开发）

**关键洞察**：APD 同时考虑**收敛性 + 多样性 + 时间动态**——这是它优于 PBI 的地方。

**强制自测**：
- 能口述 APD 比 PBI 的三个优势
- 知道为什么 RVEA 在 M ≥ 10 比 NSGA-II 强（APD 替代了非支配排序）

### P0-10：5 种主流代理模型对比（你算法选型的基础）

| 代理类型 | 输入→输出 | 优势 | 劣势 | 代表方法 |
|---|---|---|---|---|
| **Kriging / GP** | x → (μ, σ) | 自带不确定性 σ | D > 20 维难训练，O(N³) 训练 | K-RVEA, EGO |
| **RBF** | x → y | 快，对稀疏样本鲁棒 | 无不确定性 | RBF-MOEA |
| **MLP / NN** | x → y 或 x → label | 表达能力强 | 数据少时过拟合 | CSEA, REMO |
| **RF / GBDT** | x → y | 自然分类 + 集成 | 高维稀疏数据上一般 | 较少用 |
| **Polynomial** | x → y | 简单 | 高维退化 | RSM |

**关系学习代理（你的方向）的特殊性**：
- 输入是**两个解的 pair** $(x_i, x_j)$
- 输出是**关系标签**（i 比 j 好 / 否 / 等）
- 优势：**对绝对值噪声鲁棒**——只要排序对就行
- 这是 REMO 的核心 selling point

**强制自测**：
- 能说出 K-RVEA 为什么用 Kriging（要不确定性 σ 来做参考向量管理）
- 能说出 REMO 为什么用 NN 而不是 Kriging（关系判断不需要 σ；且 NN 处理分类更直接）
- 能说出 D ≥ 30 决策变量时 Kriging 的瓶颈（训练 O(N³) + 协方差矩阵不稳）

### P0-11：REMO 本体（这是你的根，必须钢印进脑子）

**REMO 的核心创新**：不学 $f(x)$（回归），学 $f(x_i) \text{ vs } f(x_j)$（关系分类）。

**全流程 6 步**（你必须能闭着眼说）：

```
Step 1: RefSelect       —— 选 k=6 个参考解（雷达图网格化）
Step 2: GetOutput_PBI   —— 对每个解打 PBI 标签（Catalog: 1=好, ≠1=不好）
Step 3: GetRelationPairs—— 配对生成关系样本 (xi, xj, label∈{1,0,-1})
Step 4: DataProcess     —— 75/25 分层采样切训练集
Step 5: patternnet      —— 训练 3 类分类器
Step 6: RSurrogateAssistedSelection —— GA 生成大量 offspring，
                            网络预测关系，
                            按"赢的次数"排序，
                            选 top-N 真实评价
```

**每一步的"为什么"你必须能答**：

- 为什么用 PBI 而不是 Pareto 标签？→ Pareto 在 M ≥ 5 全是 rank 1，分不出来
- 为什么 k=6 不是 100？→ 参考解多了训练样本数  $O(k \cdot n)$ 爆炸
- 为什么三类（1/0/-1）不是二类？→ "i 比 j 好"/"差"/"无法判断" 三种情况自然
- 为什么用 patternnet？→ MATLAB 自带，3 层 MLP 够用
- 为什么不直接选"赢"最多的？→ 还要考虑多样性

**强制自测（最重要的一个测试）**：
- 关掉 PDF，30 分钟讲清楚 REMO 整个流程
- 能回答任意一行代码"为什么这么写"

### P0-12：Learning to Rank 基础（你的 TrueSR 的理论根）

**RankNet (Burges et al., ICML 2005)**：

给定 pair $(x_i, x_j)$，定义：
$$P_{ij} = P(x_i \succ x_j) = \sigma(s_i - s_j) = \frac{1}{1 + e^{-(s_i - s_j)}}$$

其中 $s_i, s_j$ 是网络输出的标量"分数"。

**损失函数**（交叉熵）：
$$L = -\bar{P}_{ij} \log P_{ij} - (1 - \bar{P}_{ij}) \log(1 - P_{ij})$$

其中 $\bar{P}_{ij}$ 是真实标签（1.0 / 0.5 / 0.0）。

**对你 TrueSR 的对应**：
- TrueSR 当前用 MSE 损失 + sigmoid → **应该改为 cross-entropy + sigmoid**
- 这一步改动是论文级的（虽然小），它让你的方法和 RankNet 在数学上一致

**强制自测**：
- 能写出 RankNet 损失公式
- 能解释为什么 cross-entropy 比 MSE 更适合 pairwise ranking

### P0-13：Acquisition Function 基础（K-RVEA 等用的）

在 Bayesian Optimization 框架下，**Acquisition function** 决定下一个评价哪个点。

| 名称 | 公式 | 倾向 |
|---|---|---|
| **EI (Expected Improvement)** | $\mathbb{E}[\max(f^* - f(x), 0)]$ | 平衡 |
| **PI (Probability of Improvement)** | $P(f(x) < f^*)$ | 偏 exploit |
| **LCB (Lower Confidence Bound)** | $\mu(x) - \kappa \sigma(x)$ | 显式 explore/exploit |
| **TS (Thompson Sampling)** | 从后验采样 | 随机性自然平衡 |

**对你的方向**：
- 你的关系代理没有 $\sigma$，所以**不能直接用 EI/LCB**
- 解决方案：**Bootstrap Ensemble**（训练 B 个网络，方差作为 $\sigma$）
- 这就是你应该在 v0.2 里加的不确定性管理

**强制自测**：
- 能讲清楚 EI 和 LCB 的本质区别
- 知道为什么 Kriging 自带 σ 是它的核心优势

### P0-14：超多目标的核心痛点（5 大失败模式）

**这是你论文 Introduction 章节必写的内容**——必须能脱稿讲。

1. **Pareto 失效**：M ≥ 5 时随机两解互不支配概率 > 99%
2. **多样性维持困难**：高维空间 sparse，距离度量失真
3. **可视化困境**：M > 3 无法直接画 PF
4. **参考向量难匹配**：固定 reference 对 irregular PF 浪费
5. **代理样本不足**：D × M 同时高，样本相对极度稀疏

REMO 在每个痛点上的"伤"：
