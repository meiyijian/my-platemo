# 8-Week Research and Agent Execution Hub

This folder turns the 8-week plan into reusable working files for PlatEMO research.

## Start Here

1. Read `eight_week_execution_plan.md`.
2. Copy `templates/weekly_review_template.md` into a week-specific note every Sunday.
3. Log every experiment in `templates/experiment_log_template.csv`.
4. Use `workloads/workload_1_REMO_DiffUnc.md` for the first graduation workload.
5. Use `workloads/workload_2_Agent_Assisted_REMO.md` for the second graduation workload.
6. Use `D:\MyCode\research-agent-suite` for the two Agent portfolio projects.

## Daily Loop

- 2-2.5h research: read algorithm code, run experiments, inspect IGD/HV.
- 1.5-2h Agent development: tools, RAG, FastAPI, multi-agent orchestration.
- 0.5-1h review: update logs, write paper notes, polish resume bullets.

## Key Local Paths

- PlatEMO algorithms: `Algorithms\Multi-objective optimization`
- REMO baseline: `Algorithms\Multi-objective optimization\REMO`
- D_REMO baseline: `Algorithms\Multi-objective optimization\D_REMO`
- K-RVEA baseline: `Algorithms\Multi-objective optimization\K-RVEA`
- MOEA-D-EGO baseline: `Algorithms\Multi-objective optimization\MOEA-D-EGO`
- Agent suite: `D:\MyCode\research-agent-suite`

## Weekly Definition of Done

- At least one research artifact: result table, figure, method note, or code change.
- At least one Agent artifact: endpoint, tool, test, README section, or demo.
- One weekly review note with the next week priority.
- One resume/interview bullet updated from actual work.
