## 网络问题与解决方案（重要）

拉取时遇到 TLS 连接错误：
```
fatal: unable to access 'https://github.com/meiyijian/my-platemo.git/':
TLS connect error: error:0A000126:SSL routines::unexpected eof while reading
```

**根因**：git 全局配置了代理 `http.proxy=http://127.0.0.1:7897` 和 `https.proxy=http://127.0.0.1:7897`（Clash 代理端口），但该代理进程当前未运行，导致所有 git over https 操作失败。

**解决方案**：临时禁用代理直连（不修改全局配置）：
```bash
git -c http.proxy= -c https.proxy= pull origin master
git -c http.proxy= -c https.proxy= merge --ff-only origin/master
```
注意：`git pull` 在 fetch 成功但合并阶段若返回非零退出码，本地可能仍落后，需手动 `git merge --ff-only origin/master` 完成快进。

**下次建议**：先确认代理是否运行；若不需要代理，可执行 `git config --global --unset http.proxy` 和 `git config --global --unset https.proxy` 清除全局代理配置。
