## 从已有 .mat 补算 IGD+（不重跑算法）—— 机制与 HV 大坑

用户：「我的实验数据已经有了 IGD 数据，可以计算 IGD+ 或者 HV 吗」「先算我当前算法的十目标数据，分文件夹保存」，
随后改为「只算 IGD+，算我当前算法 + 论文里六个算法」。

**只读补算的完整机制（本次最有价值的结论）**：
- 存盘 `.mat` = `result`(cell n×2) + `metric`(struct runtime/IGD) + `metadata`（Lambdat030 有 metadata，六基线老数据没有）。
  `result{k,1}`=第 k 个快照的 FE，`result{k,2}`=该快照的 SOLUTION 数组（`objs` 可用）→ **指标可以事后全部重算，不必重跑**。
- 官方补算入口：`ALGORITHM.CalMetric(name)` → `Problem.CalMetric(name,pop)` → **`feval(name, pop, obj.optimum)`**（`PLATEMO/Problems/PROBLEM.m:279`）。
- **参考集是 `pro.optimum`，不是 `pro.PF`**！`PROBLEM` 构造函数（`PROBLEM.m:86-87`）：
  `optimum = GetOptimum(10000)`、`PF = GetPF()`。DTLZ/WFG 在 **M>3 时 `GetPF()` 返回空**（DTLZ1.m:43-45），
  所以拿 `PF` 当参考集必然算出 NaN。DTLZ1 的 `GetOptimum = UniformPoint(10000,M)/2`，**M=10 去重后是 7007 个点**（不是 10000）。
- 同一题所有算法共用同一 `optimum`（只由题目类+M 决定，与算法/种子无关）⇒ **IGD/IGD+/GD 跨算法天然可比**，无需统一参考点。
- 速度实测（M=10 D=30）：IGD+ 单快照约 0.03 s（含 NDSort），**全 30 快照约 0.8–1.0 s/文件**；构造 Problem 0.01–2.1 s（WFG1 最慢）。

**HV 在 M=10 基本不可用（已实测，用户遂放弃 HV）**：
- `Metrics/HV.m`：**M≥4 走 Monte Carlo，SampleNum=1e6**；参考点由 `fmax = max(optimum)×1.1` 归一化，
  然后 `PopObj(any(PopObj>1,2))=[]` **把任一维超界整行丢掉**。
- 后果：DTLZ 的 PF nadir 只有 0.5(DTLZ1)/1(DTLZ2–6)/20(DTLZ7)，而 M=10 的解目标值能到 1366/2802/78
  ⇒ **DTLZ1、3、4、5、6、7 的 HV 恒为 0，DTLZ2 仅 1.2e-4**；WFG 系列正常（0.21–0.45）。
- 若一定要算：自定义参考点 `1.1×max(该题全部跑全部快照各维最大值, PF nadir)`（实测 DTLZ2 恢复到 0.914、DTLZ7 0.669），
  代价是丢失「跨算法统一口径」；且全快照 HV 约 **1.3–3.4 s/快照**（5.7 h/320 文件单线程），比 IGD+ 重约 30 倍。
- HV 另有蒙特卡洛随机性 → 必须固定 `rng` 才能比较。

**数据规模（`10目标\n30`，M=10 D=30/31，16 题）**：六基线 `REMO / PIEA / CSEA / PCSAEA_N100 / KRVEA_100 / MCEAD` 各 **30 跑 = 480 文件**；
`REMO_UniformMix_Pruned_Weighted_Lambdat030`（= 论文 PACDIS）**20 跑 = 320 文件**。WFG2/WFG3 的 D=31（PlatEMO 自动上调）。

## 续：15/20 目标 IGDp + 复刻论文格式表格（PlatEMO 表格口径全解）

用户给出参考表 `AdaMao实验表\lambdat030版本\IGDp10目标.xlsx`，要求按同格式补出 15/20 目标，
`+/-/=` 按 PlatEMO 方法，单元格数据是 mean(STD)。

**PlatEMO 表格口径（`PLATEMO\GUI\module_exp.m`，逐条确证，以后做表一律照此）**：
- 指标取法：`GetMetricValue` → `PRO(p).CalMetric(name,S)` 对 `result(:,2)` 逐快照算后取 **(end)**（module_exp.m:448-471）；
  顺手 `save(...,'metric','-append')` 会把新指标写回原 `.mat`（所以"某目录里没有 IGDp 字段"可推断没用 GUI 算过）。
- **mean/std 用「各算法全部可用 run」**（:344-348），**不做样本截断**。
- 文本 `sprintf('%.4e (%.2e)')`，再把 `e-0`→`e-`、`e+0`→`e+`（:354-358）；半角括号，均值与括号间一个空格。
- **符号用截断样本**：`minlen = min(各算法 run 数)`，各算法取**前** `minlen` 个，`ranksum(基线, 提出算法) < 0.05`（:371-392）。
  **默认 `dropC(3)=3` 即 rank sum test（ranksum，独立样本），不是 signrank**。
- 符号语义：`不显著 或 均值相等 → '='`；`mean(基线)<mean(提出) 且指标越小越好 → '+'`；否则 `'-'`；符号以 `' '` 追加在文本尾部；
  **最后一列（提出算法）一律不带符号**。
- 汇总行 `+/-/=` 计数顺序是 **`+ / - / =`**（不是 `+ / = / -`）。
- 格式：Times New Roman 11、全部居中、A1:J18 全区细边框、无底色、**每行最小值字体蓝 `#3333E9`**、`A18:C18` 合并放 `+/-/=`。
  参考表实测列宽（openpyxl 字符宽）A=10.625 / B=6.625 / C=13.0 / D=22.625、行高 15。
