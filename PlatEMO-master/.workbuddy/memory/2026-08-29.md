### 关键坑：genpath 全局路径下的同名 helper 遮蔽（务必记住）

- `platemo.m` 用 `addpath(genpath(cd))`，MATLAB **按文件名**解析（不是文件内函数名，如 `CrowdingDistance.m` 里定义的是 `CrowdDis`），且不区分调用者所在目录 → 字典序靠前的目录会遮蔽后面所有同名文件
- 直接复制 35 个新目录会产生 **15 个被抢占的函数名**，其中 `Shape_Estimate.m` 最危险：新增的 `MaOEA-HAP` 版签名是 `(Population,N,z,znad)` 四参数，而 PIEA / PIEA_R / PIMD / REMO_SDE / **REMO_new2_AdaMaO** / REMO_new2_AdaMaO_Simple(A) / REMO_new2_PIEA3-5 调用的是两参数版 → 会直接报错
- 解决办法：把新增目录中**与既有目录重名的 .m 文件**移入该目录自己的 `private/` 子目录
  - `genpath` 会跳过 `private`，故不进入全局路径，对既有代码零影响
  - MATLAB 中 `private/` 对父目录函数优先级最高，新增算法仍能调用自己的 helper
  - 本次共隔离 **127 个文件**；复核后新增目录在全局路径上的重名文件数为 **0**
  - `readList2` 也走 genpath，主类文件（classdef < ALGORITHM）留在顶层，GUI 仍能发现新算法

### 操作方式（下次同步可直接复用）

1. `git clone --depth 1 --filter=blob:none --sparse https://github.com/BIMK/PlatEMO.git` → `git sparse-checkout disable`
2. 用文件名（非函数名）建索引做双向 diff，识别「官方有本地无」与「本地有官方无」；改名目录需逐文件 diff 确认，不要重复引入
3. 复制后立即做重名扫描，按上述 private 方案隔离
4. 隔离后复核两类孤儿：① 仅由新增目录提供、却被其它新增目录调用的名字（本次 `CreateGroups` 一度中招，后确认调用方自带同名子函数，属误报，最终仍留在 private）；② 全局路径上新增目录的重名残留数须为 0
5. 不要整体升级 GUI/框架文件——本地仍是 v4.12，升级会引入不可控改动
