### ⚠️ 并发上限的真相（值得记住）
`parcluster('Processes').NumWorkers = 6` —— 这是 **MATLAB profile 的默认上限**，而本机有
**12 个逻辑核、`NumThreads = 1`**。也就是说过去所有批次都白白空置了一半 CPU，
「5 workers 最优」的经验很可能是被这个上限误导出来的。
runner 已改成**只在本会话内**突破：
```matlab
c = parcluster('Processes');
if workers > c.NumWorkers
    c.NumWorkers = workers;     % 会话内生效
end
pool = parpool(c,workers);      % 不调用 saveProfile，存储配置不动
```
