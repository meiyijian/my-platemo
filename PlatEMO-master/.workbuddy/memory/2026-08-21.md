## 新建算法 REMO_UniformMixCandidate

- 需求：以基础 REMO 为框架，仅把候选解模块替换为 REMO_new2_AdaMaO_SDEOnly_UniformMix_Original 的候选解模块，其余不变。
- 目录：`PlatEMO/Algorithms/Multi-objective optimization/REMO_UniformMixCandidate/`
- 主文件：`REMO_UniformMixCandidate.m`（参数 k=6, gmax=3000, pMix=0.50, qKeep=0.80, lambda0=0.35, nMin=4, nMax=6）
- 框架部分（来自基础 REMO 原版，未改）：RefSelect / GetOutput_PBI / GetRelationPairs / DataProcess / onehotconv + patternnet 训练。
- 候选模块部分（来自当前算法）：AdaMaOSelection + ResolveUniformMixMode + CreateSDECandidateModeStream + IndicatorSelectorSDEOnly + calFitness_SDE + Shape_Estimate。
- 关键差异：框架用 REMO 的 GetOutput_PBI（自适应二分类 30%~70%）+ RefSelect(k=6)，而非当前算法的 HybridPBI_Classification(rGood=0.25)+k_eff；因此新算法不含 rGood 参数。
- 所有 helper 放 private/，函数名与文件名已逐一核对一致，依赖无缺失。
