# 01 · 算法总览与定位（模块0）

> **一句话定位**：REMO_new2_AdaMaO 是 REMO_new2_WFG10 的**自适应版本**。核心改动只有一句话——**让算法根据运行时的种群状态，自动切换「关系对训练策略」和「候选解选择策略」，而不是像前一版那样用一套固定策略跑到底。**

---

## ① 它解决什么问题？（动机）

你已经知道 REMO 家族是做**昂贵高维多目标优化**的：真实评估代价高（`maxFE` 严格受限），目标维数 M 大导致标准支配关系失效，于是用神经网络学「解的偏好关系」来指导采样。

WFG10（前作）引入了置信度加权、不确定性、多样性选择，但**策略是写死的**：
- 不管早期模型准不准，都用同一套加权训练 → **早期模型不准时，加权会把噪声放大**
- 不管后期种群散不散，都用同一套选择 → **后期种群退化时，关系得分分不清好坏了**

AdaMaO 的解法：加一个「传感器」（运行时诊断）+ 两个「开关」（动态训练模式、动态选择模式），让算法自己看情况切换。

> 🔑 记忆点：AdaMaO 的创新不是"新模块堆得更多"，而是"让老模块能自适应切换"。

---

## ② 主链 4 步（记忆锚点，务必背下来）

后面所有花哨模块，都是挂在下面这条链上的"增强"。被追问时，一切细节都能挂回这 4 步：

```
初始化种群 + Archive
      │
      ▼
① HybridPBI 混合分类  →  好/坏标签 Catalog + 置信度 confidence + 参考解 Ref
      │
      ▼
② 运行时诊断          →  coverage（覆盖度）+ degeneracy（退化度）
      │
      ▼
③ 动态切换策略         →  关系对训练模式 / 候选解选择模式（由 ② 的两个量决定）
      │
      ▼
④ 关系模型训练 + AdaMaOSelection 候选筛选 → 真实评估 → RefSelect 环境选择
      │
      └─────────────── ↺ 回到 ① 循环，直到评估预算用尽
```

**主链 4 步的对应关系（代码行号见 `REMO_new2_AdaMaO.m`）：**
- ① 调用 `HybridPBI_Classification`（L90）
- ② 调用 `RuntimeDiagnostics`（L97）
- ③ 两个 `if/elseif` 决策块（L114–119 关系对模式；L198–203 候选模式）
- ④ `TrainRelationModel`(L148) → `AdaMaOSelection`(L224) → `Problem.Evaluation`(L241) → `RefSelect`(L269)

## ③ 两套"开关" + 一个"传感器"

### 开关 A：动态关系对训练模式（决定"怎么教神经网络"）
| 模式 | 触发（逻辑） | 干什么 | 来源 |
|---|---|---|---|
| `conservative` | 默认 | 原始关系对，无权重，最稳 | 来自 REMO |
| `curriculum` | 上一代模型误差大 | 只留高置信度样本，过滤噪声（课程学习） | 自创 |
| `weighted` | 模型准 + 置信度高 + 覆盖低 | 置信度加权，让靠谱样本影响更大 | 来自 WFG10 的加权思想 |

### 开关 B：动态候选解选择模式（决定"选哪些解去真实评估"）
| 模式 | 触发（逻辑） | 干什么 | 来源 |
|---|---|---|---|
| `conservative` | 默认 | 只按关系得分选少量解 | 来自 REMO |
| `explore` | 模型准 + 覆盖低 | 关系得分 + 不确定性 + 多样性，鼓励探索 | 自创 |
| `indicator` | 有指标模型 + 退化高 | 用 PIEA 风格指标重排 | 借用 PIEA |

### 传感器：运行时诊断（两个量，驱动上面两个开关）
- `coverage`（覆盖率）：种群覆盖了多少个参考方向 → 低则多探索 / 触发加权
- `degeneracy`（退化度）：种群是否挤在低维子空间 → 高则触发指标增强多样性

## ④ 借来的 vs 自创的（学算法最该分清的事）

| 成分 | 来自哪 | 在 AdaMaO 里的作用 |
|---|---|---|
| 关系学习框架（好/坏对 + patternnet） | REMO | 核心骨架，不变 |
| HybridPBI 分类 | REMO/WFG10 | 产出标签，升级版 HPC |
| 置信度加权 / 不确定性 / 多样性 | WFG10 | 被"动态触发"地复用 |
| **运行时诊断（coverage/deg）** | **AdaMaO 自创** | 传感器的来源 |
| **动态策略切换逻辑** | **AdaMaO 自创** | 两个开关的灵魂 |
| PIEA 指标轮盘（SDE/I_eps+/Minkowski） | **直接借用 PIEA** | 候选选择的"增强"（⚠️ 可删） |
| RefSelect 雷达网格 | RSEA | 环境选择，不变 |

> ⚠️ **投稿实用性提示**：消融实验已证明，直接借用的 PIEA 指标子系统**对 IGD 无统计显著增益，且在断开 PF（DTLZ7）会塌缩**。作者推荐的最终版是 **AdaMaO-Lite（删掉整条指标子系统）**。所以：教学上要学全（理解每个模块），但讲论文时要清楚"哪些该留、哪些该砍"。

## ⑤ 超参数一览（先混个眼熟，别背）

| 参数 | 默认 | 含义 | 来源 |
|---|---|---|---|
| `k` | 6 | 参考解数量基数 | REMO |
| `gmax` | 3000 | 内层 GA 累计样本上限 | REMO |
| `q_keep` | 0.80 | 候选筛选分位数阈值 | WFG10 |
| `lambda0` | 0.35 | 不确定性权重基础系数 | WFG10 |
| `w_min` | 0.30 | 样本权重下限 | WFG10 |
| `n_min/n_max` | 4/6 | 每轮真实评估最少/最多数 | WFG10 |
| `tau_err` | 0.35 | 模型误差阈值（切关系对模式用） | **新增** |
| `use_indicator` | 1 | 是否启用指标轮盘 | **新增** |
| `debug` | 0 | 是否打印调试 | **新增** |

> 老师若问阈值数字，答："初步经验阈值，正在内生化成由问题规模（N/M/D/FE）自动决定。"

## ⑥ 与 REMO_new2 / WFG10 的横向对比（一眼看懂"多了什么"）

| 维度 | REMO_new2 | WFG10 | AdaMaO |
|---|---|---|---|
| 关系对生成 | 无权重 | 固定加权 | **动态三选一** |
| 候选解筛选 | 固定阈值 | 分位数+不确定性 | **动态三选一** |
| 指标选择 | 无 | 无 | **新增 PIEA 轮盘** |
| 运行时诊断 | 无 | 无 | **新增 coverage/deg** |
| 外部超参数 | 2 个 | 7 个 | 10 个 |
