# 02 · 初始化与主循环骨架（模块1）

> **一句话定位**：模块 1 是算法的"外壳"——它负责把初始种群建出来、把所有跨代持久的状态准备好，然后用一个 `while` 主循环把后面 8 个模块（分类 / 诊断 / 训练 / 选择 / 评估 / 反馈）按顺序串起来。骨架本身没有创新（沿用 REMO 昂贵优化框架），但**所有模块都挂在它上面**。

源码位置：`REMO_new2_AdaMaO.m` 的 `main` 函数。
- 初始化：L20–L73
- 主循环：`while Algorithm.NotTerminated(Archive)`（L76–L270）

---

## ① 初始化做了哪几件事？

按顺序（对应 L20–L73）：

### (a) 参数设定 `ParameterSet`（L31–L32）
```matlab
[k,gmax,q_keep,lambda0,w_min,n_min,n_max,tau_err,use_indicator,debug] = ...
    Algorithm.ParameterSet(6,3000,0.80,0.35,0.30,4,6,0.35,1,0);
```
10 个外部参数（详见大纲模块 0 的「超参数一览」）。这是 AdaMaO 相比 REMO（2 个）臃肿的根源之一，也是后续 AdaMaO-S 要内生化的对象。

### (b) 种群规模 N 的确定（L37–L41）
```matlab
if Problem.D <= 10
    N = 11*Problem.D - 1;   % 低维：随 D 增长
else
    N = 100;                % 高维：固定 100（昂贵 MO 标准规模）
end
```
- `D` 是**决策变量维度**（不是目标维 M）。低维用经验公式，高维直接 100。
- 你已知道 REMO 是昂贵优化，N 不需要大——真实评估很贵，靠 Archive 累积。

### (c) 拉丁超立方采样 + 真实评估（L43–L47）
```matlab
PopDec     = UniformPoint(N,Problem.D,'Latin');      % [0,1] 均匀采样
Population = Problem.Evaluation(                       % 映射到决策空间并真实评估
    repmat(Problem.upper-Problem.lower,N,1).*PopDec + repmat(Problem.lower,N,1));
```
- `UniformPoint(...,'Latin')`：拉丁超立方采样，保证初始解在决策空间均匀铺开（比纯随机覆盖更好）。
- `Problem.Evaluation`：**真实评估**，每调用一次就消耗预算 `maxFE`。这是"昂贵"二字的代价所在。

### (d) Archive 累积器（L49）
```matlab
Archive = Population;
```
- **Archive = 有史以来所有真实评估过的解**（只增不减）。它是算法的最终输出。
- 与 `Population` 区分：`Population` 是当前这一代的 N 个解（由环境选择从 Archive 挑出，见模块 9），用于下一轮分类；`Archive` 是"记忆库"。
- 🔑 记忆点：**Population 是"这一代的工作集"，Archive 是"全部记忆 + 最终答案"**。

### (e) PIEA 指标轮盘初始化（L51–L66）
```matlab
tau_indicator = 20;   % 滑动窗口大小（记录最近 20 代的选择/成功）
indicator(1) = struct('method','SDE',         'Choose_record',ones(1,20),'Win_record',ones(1,20),'Pw',1/3);
indicator(2) = struct('method','I_epsilon+',  ...);   % 同上
indicator(3) = struct('method','Minkowski',   ...);   % 同上
```
- 这是**直接借用 PIEA** 的轮盘赌状态：三种指标（SDE / I_epsilon+ / Minkowski）初始等概率 `Pw=1/3`。
- `Choose_record`：近 20 代被选次数；`Win_record`：被选后"成功"次数。每代用 `Pw = Win/Choose` 更新（模块 6/9 细讲）。
- 这里只是**初始化**，真正"选指标 + 反馈更新"在模块 6、9。
- `tau_indicator=20` 是滑动窗口长度，对应组会稿里的"最近 20 代"。

### (f) 跨代标量状态（L71–L73）
```matlab
Lp         = 1;     % PF 形状参数估计初值（模块 6 动态估计）
prev_p_err = 1;     % 上一代关系模型的测试误差（模块 3/4 决策用）
gen        = 0;     % 代数计数器
```
- `prev_p_err` 是**自适应反馈的关键**：它把"上一代模型准不准"带给这一代，决定关系对模式是否切到 curriculum。

## ② 主循环骨架（执行顺序 = 记忆锚点的展开）

`while Algorithm.NotTerminated(Archive)`（L76）。循环条件看 Archive 的已评估次数是否到 `maxFE`——再次印证"昂贵"靠预算终止。

每一代内部按固定顺序执行（背下这个顺序，后面每个模块就是其中一步）：

| 顺序 | 代码 | 步骤 | 对应主链 | 模块 |
|---|---|---|---|---|
| 1 | L80 | `ratio = FE/maxFE` 进化比例 | — | （驱动加权/探索权重） |
| 2 | L85 | `k_eff = min(N, max(k, ceil(1.5*M)))` 自适应参考解数 | — | （模块 2 用） |
| 3 | L90 | `HybridPBI_Classification` → Catalog, confidence, Ref | ① | 模块 2 |
| 4 | L97 | `RuntimeDiagnostics` → coverage, degeneracy | ② | 模块 3 |
| 5 | L114 | 决策**关系对模式** conservative/curriculum/weighted | ③ | 模块 4 |
| 6 | L125 | 按模式生成关系对 → XXs, YYs, WWs | ③ | 模块 4 |
| 7 | L148 | `TrainRelationModel` → net, p_err | ④ | 模块 5 |
| 8 | L160 | （可选）`IndicatorSelector` + 训练 SVR 指标模型 | ③/④ | 模块 6 |
| 9 | L198 | 决策**候选解模式** conservative/explore/indicator | ③ | 模块 7 |
| 10 | L207 | 组装 `Smodel` 结构体（传给选择模块） | ④ | 模块 7/8 |
| 11 | L224 | `AdaMaOSelection` → Next 候选解 | ④ | 模块 8 |
| 12 | L229 | 若 Next 空，退回普通 GA 生成备选 | ④ | 模块 8 |
| 13 | L241 | `Problem.Evaluation(Next)` → 并入 Archive | ④ | — |

## ③ 几个必须懂的"廉价但关键"细节

### ratio（L80）
`ratio = Problem.FE / Problem.maxFE`，范围 0→1，表示进化进度。
- 模块 7（explore 模式）用它让"不确定性探索权重"随进化递减：`lambda_t = lambda0 * (1-ratio) * ...`——早期多探索，后期少探索。

### k_eff（L85）
`k_eff = min(N, max(k, ceil(1.5*M)))`：参考解数量 = k(=6) 和 1.5×M 取大，但不超 N。
- 高维目标 M 大 → 需要更多参考解覆盖 PF。这是 WFG10 引入的"自适应参考解"，AdaMaO 沿用。

### Smodel 结构体（L207–L219）
把这一代算出的所有"模型资产"打包成一个 struct，传给 `AdaMaOSelection`：
```matlab
Smodel.X, Smodel.Y        % 训练数据（决策变量 + 好/坏标签）
Smodel.net, Smodel.mp_struct  % 神经网络 + 归一化参数
Smodel.p_err              % 模型误差（切模式 + 探索权重用）
Smodel.IndicatorModel     % SVR 指标模型（可能为 empty）
Smodel.mode               % 候选解模式（conservative/explore/indicator）
Smodel.q_keep, n_min, n_max
```
- 这是模块 8（选择）的输入契约——理解了它就理解了"前面 7 步为第 8 步备料"。

### 失败兜底（L229）
```matlab
if isempty(Next) && remain > 0
    Next = OperatorGA(Problem,[Population.decs;Ref.decs],{1,15,1,5});
    Next = Next(1:min(n_min,size(Next,1)),:);
end
```
- 若代理选择没产出候选（极端情况），退回普通 GA 生成 `n_min` 个，保证循环不空转。

## ④ 与 REMO / PIEA 的连接

| 初始化/骨架元素 | 来自 | 说明 |
|---|---|---|
| 拉丁超立方 + 真实评估 + Archive 累积 | REMO | 昂贵优化标准套路，不变 |
| N 的确定（低维公式 / 高维 100） | REMO | 不变 |
| 轮盘初始化 struct（SDE/I_eps+/Minkowski, Pw=1/3） | **PIEA** | 借用，本模块只初始化 |
| `ratio` / `k_eff` 自适应量 | WFG10 | 沿用 |
| `while NotTerminated(Archive)` 预算终止 | REMO | 昂贵优化核心 |

> **本模块无 AdaMaO 自创内容**——它纯粹是"把已有积木摆好、规定好每代先干啥后干啥"。真正的创新在模块 3（诊断）和模块 4/7（开关）。

## ⑥ 常见误区：maxFE=300 到底能跑多少代？

> 学员常算成「300 ÷ 4 = 75 代」，这是错的。两个隐藏开销没算进去：

**(1) 初始化 LHS 在 `while` 循环之前就先吃掉 N 个预算（L45，gen=0）。**
- D=30 时 `N=100`（L40），所以一开始已花 **100 / 300**。
- 这次评估**不进主循环、不算"一代选择"**，但实打实计入 `maxFE`。

**(2) 每代真实评估的是 4~6 个，不是固定 4 个（AdaMaOSelection 的 `n_min`/`n_max`，L40/L43）。**
- `select_conservative` → 固定 `n_min = 4`
- `select_explore` / `select_indicator` → `min(n_max, max(n_min, cand数))` ∈ [4, 6]

**正确账本（maxFE=300, N=100）：**

| 项目 | 数值 |
|---|---|
| 总预算 | 300 |
| 初始化 LHS 已花 | N = 100 |
| 留给"代"的预算 | 200 |
| 每代消耗 | 4（最少）~ 6（最多） |
| 最多代数（每代都评 4） | 200 / 4 = **50 代** |
| 最少代数（每代都评 6） | 200 / 6 ≈ **33 代** |

- `while` 循环跑约 **33~50 次**（gen 从 1 数到 33~50），前面还有 gen=0 的初始化。
- 代数受模式配比影响：conservative 为主 → 偏 4/代（代数多，近 50）；explore/indicator 多 → 偏 6/代（代数少，近 33）。
- 最后一代若 `remain < 4` 会被截断成评 1~3 个（L239）。
- 唯一真实评估点：L45（初始化）+ L241（每代 `Problem.Evaluation(Next)`）；分类/诊断/训练都不花真实预算。
