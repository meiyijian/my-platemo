**pMix = 0.50 是全 12 个 (M, 问题) 格的最优默认值（平均秩最低 2.621、最差秩最小 3.00，且显著优于 pMix ≥ 0.75），但并非"处处最优"——它只在 2/12 格夺冠，且与 pMix = 0.25 统计上不可分。**

## 4. 结论（可直接写进论文）

1. **pMix = 0.50 是全 12 格的最优默认值**：平均秩最低（2.621）、最差秩最小（3.00），合并 240 配对块 Friedman p < 1e-6，且**显著优于高段 pMix = 0.75（Holm p = 0.030）与 pMix = 1.00（Holm p = 0.00036）**。
2. **但不能称其"处处最优"**：只在 2/12 格夺冠，且**与 pMix = 0.25 统计上不可分（Holm p = 1.0）**。
3. **效应强烈依赖问题、方向会翻转**：
   - 偏好**高** pMix：DTLZ2、WFG3（两个 M 一致）、WFG1（弱）
   - 偏好**低** pMix：DTLZ7、WFG8、DTLZ4（仅 M=10）
   - **DTLZ7 最敏感**：pMix = 1.00 相对 0.50 差 **+81.0%（M=10）/ +73.8%（M=20）** → 纯指标准则对 DTLZ7 是灾难。
4. **极端臂互补，所以"折中"赢**：pMix0 vs pMix1.00 合并检验 **p = 1.0**（谁也没赢），因为二者各自在互不相交的问题子集上取胜。这正是中间值在平均秩上占优的机制。
5. **pMix = 0（完全不启用指标分支）是最危险的选择**：最差秩 5.00；DTLZ2 上比 0.50 差 **+30.9%（M=10）/ +11.2%（M=20）**。

**建议的论文表述**：*性能对 pMix 敏感，但效应方向随问题翻转；pMix = 0.50 给出最优的平均秩与最差情况表现，并显著优于 pMix ≥ 0.75，与 0.25 统计不可分——因此作为稳健默认值而非调优最优点。*

## 5. 方法学要点（本次实测得到，后续实验必须遵守）

1. **pMix 不进入随机数流**：算法每轮无条件执行 `u = rand(modeStream,1)`，pMix 只在 `ResolveUniformMixMode` 里决定用哪条准则（`indicator` 当且仅当指标模型可用且 `u < pMix`）。
   → 五臂共享同一随机序列，是**严格的配对设计**（已实测：每个 (问题, run) 的首个 IGD 快照五臂逐位一致）。因此本次全部用配对检验。
2. 🔴 **`maxNumCompThreads` 不是行为中性的**：对含 `patternnet`/`fitrsvm` 的算法，它只改浮点归约顺序，但会被后续几十轮"模型驱动候选选择"混沌放大。实测 WFG1/M=20/run1：threads=2 与 threads=1 两组**FE 列表逐位相同、前 5/30 个 IGD 快照逐位相同，第 6 个快照起分岔**，最终 IGD 差 4e-3 ~ 1e-1。
   → **同一张对比表里绝不能混用不同线程数**。本次五臂统一 threads = 1。
   → 推论：`D:\REMOandDREMO测试集\20目标\REMO_UniformMix_Pruned_Weighted_Lambdat030`（threads=2 的旧基线）**不能当作 pMix=0.50 这一臂使用**。
3. **单跑成本与目标数 M 几乎无关**：用同族数据集实测 M=10/M=20 成本比 ≈ 0.94–1.01（REMO、REMO_new2）；耗时被神经网络/代理训练主导，而那只取决于 D 和 N。**排期时别按"降 M 会变快"估**。
4. 计时（12 路并行 × threads = 1，本机 16 逻辑核）：DTLZ2 ≈ 420 s、WFG1 ≈ 383 s、WFG3 ≈ 377 s、WFG8 ≈ 368 s；进程池利用率 ≈ 98%。
   两轮总耗时约 10 h 50 min（第一轮 09-15 16:28→20:20 完成 439 跑；第二轮 09-16 01:24→08:19 补完 761 跑，6 h 55 min）。

```bash
import glob, os, re, numpy as np
from scipy.io import loadmat
from scipy import stats
# 纯 ASCII 递归 glob，绕开路径里的中文
files = glob.glob('D:/REMO*/**/REMO_UniformMix_Pruned_Weighted_Lambdat030_pMix*/*.mat', recursive=True)
fname_re = re.compile(r'_(DTLZ\d|WFG\d+)_M(\d+)_D(\d+)_(\d+)\.mat$')
pm_re    = re.compile(r'pMix(\d+)')
data = {}
for f in files:
    mm, fm = pm_re.search(os.path.basename(os.path.dirname(f))), fname_re.search(os.path.basename(f))
    if not (mm and fm): continue
    pmix, prob, M, r = int(mm.group(1)), fm.group(1), int(fm.group(2)), int(fm.group(4))
    igd = np.asarray(loadmat(f)['metric']['IGD'][0,0]).ravel().astype(float)
    data.setdefault((M, prob, pmix), {})[r] = igd[-1]     # 末位 = 最终 IGD
ARMS = [0,25,50,75,100]
cells = []
for M in (10,20):
    for p in ['DTLZ2','DTLZ4','DTLZ7','WFG1','WFG3','WFG8']:
        rs = sorted(set.intersection(*[set(data[(M,p,a)]) for a in ARMS]))   # 配对 run 交集
        cells.append((M, p, rs, {a: np.mean([data[(M,p,a)][r] for r in rs]) for a in ARMS}))
blocks = np.array([[data[(M,p,a)][r] for a in ARMS] for M,p,rs,_ in cells for r in rs])
print('配对块数 =', len(blocks))
print(stats.friedmanchisquare(*[blocks[:,j] for j in range(5)]))   # chi2≈44.9, p<1e-6
for i in range(5):
    for j in range(i+1,5):
        print(f'pMix{ARMS[i]} vs pMix{ARMS[j]}: raw p = {stats.wilcoxon(blocks[:,i], blocks[:,j]).pvalue:.6f}')
PYEOF
```
