## 三、算法线：UniformMix 家族的参数削减实验

### 3.1 一周内在 `Algorithms/Multi-objective optimization/` 新增的 3 个变体

| 变体 | 探索分支的选择规则 | 与 Original 的差别 |
|---|---|---|
| `..._UniformMix_Maximin` | 选择离**完整历史档案**最远的候选（Maximin） | 距离对象是历史档案，不是当前批次 |
| `..._UniformMix_Pruned` | 首点取关系得分最高，后续点取**批内最大最小距离** | 同时删 5 项（见下） |
| `..._UniformMix_Pruned_Weighted` | 每步在剩余候选上对关系得分与距离分别 min-max 归一化，取 `0.75·R̂ + 0.25·d̂` 最大 | 在 Pruned 基础上**只回填这一项** |

`Pruned` 一次性删除的 5 项：① 指标分支 0.70 分位阈值 ② `nMin=4` ③ `lambda0=0.35` 与 0.45 误差门控（含模糊度奖励及其进度衰减）④ 指标粗筛"最少 20 个" ⑤ 批次得分-距离权重 0.75/0.25。**这是五项组合版本，不是单因素消融**——性能变化不能归因于其中任一项。

三个变体都自带了 README + tests + `validation.log`，`Pruned_Weighted` 还有 `frozen_baseline_manifest.json`（15 个基线源文件的 SHA256）与 `freeze_verification.json`。**冻结/校验这一层做得比之前规范，可以继续沿用。**

| DTLZ5 | 0.652800 | 0.896616 | 0.855579 | **+31.06%** |
| DTLZ7 | 12.063501 | 18.617720 | 10.766713 | −10.75% |

### 3.4 机制诊断：四位嫌疑人的可信度分层

| 优先级 | 假设 | 证据强度 |
|---|---|---|
| 一 | 删掉 0.75 权重后，质量从"持续排序依据"退化成"入场门槛" | 强。性质上原版有"质量差超过 1/3 时距离无法翻盘"的保护，Pruned 没有；人工候选池检查中原加权选 [1,2]、Pruned 选 [1,6] |
| 二 | 本次 `qKeep=0.70`（原版 0.80）把探索合格集合放宽约 50% | 中。与第一项存在合理交互，**现在不能把损失分配给其中任何一项** |
| 三 | 删除模糊度奖励 | 弱。原奖励在 `p_err≥0.45` 时为 0 且随进度衰减，但存档里没有候选预测/p_err/实际 lambda_t，无法判断它原本有多活跃 → 排到第二阶段独立验证 |
| 四 | `nMin=4`、指标 0.70 分位点、"最少 20 个" | 基本可排除。当去重候选数 `C≥64` 时，`ceil(0.30C)≥20`，三者与原版等价；已用 80 个有限分数/关系回退的 MATLAB 检查验证一致 |

**明确的收敛证据**：DTLZ2/5 都有收敛项 `g(x)=Σ(x_j−0.5)²`。Pruned 在这两题上**初始 100 FE 的平均 IGD 反而略好**，但 200/300 FE 落后 → 不是"初始化更差"，而是后期没收敛。诊断性投影（把第 10–30 维固定为 0.5 后重算目标）显示 Pruned 的覆盖并不差（DTLZ2 0.553 vs 0.598），**问题在于点没有充分收敛**。

**已排除的解释**：未用足预算、档案内精确重复评价、初始化平均更差、PAQC/SDE/训练划分被一起改动（共享源码哈希一致）。

### 3.5 几条第 3.5 节之外值得记住的技术边界

- **固定全局种子不能靠 `rng()` + `platemo(...)`**：本地 `platemo.m` 入口会执行 `rng('shuffle')`。要做同种子对照，必须"直接构造 problem/algorithm 对象，在 `Solve` 前设 `rng(seed,'twister')`"。
- **WFG2/WFG3 原版数据文件实际是 D=31**，其余是 D=30。不要为了统一文件名把实际 D 改回 30。
- **加权前必须用欧氏距离，不能用平方距离**——排序等价但归一化后的数值不等价。
- `Pruned` 源码默认 `qKeep=0.80`，但正式实验是**通过配置覆盖为 0.70** 跑出来的；两个入口比较时要显式都传 `{3000,0.50,0.25,0.70,6}`。
- 秩和检验用的是 exact Wilcoxon（独立样本，非配对）——因为三个版本之间**没有共同初始样本**，只是运行编号对齐。

### ⚠️ 一处需要你注意的口径不一致

`1param` 草稿把"质量-距离加权"折进单一 bonus β 里（`β=0` 时批次退化为按关系得分取 top-n_b）；而算法侧最新的 `Pruned_Weighted` 恰好证明**把这个权重删掉会退化、回填后部分恢复**。也就是说 **β 取 0 附近对应的正是被实验否定的那一格**。
