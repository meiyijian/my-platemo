| k=6, M=10 | ✓ | ✓ | ✓ | **缺** |

| k_eff, M=10 (k=15) | ✓ | ✓ | **缺** | ✓ |

**`REMO_Candicate_20.xlsx` 里那个无 k 标注的 `full` 列身份确认了：它就是 full at k=6。**
证据：DTLZ1 60.26 与 `REMO+candidate`(k=6) 的 60.75 同量级，而 `full (k=30)` 是 79.75；
且它与 `full (k=30)` 的差异方向与 §3 的 k 效应（WFG 正、DTLZ 负）逐格自洽。

**所以 2×2 不是"要不要跑"，而是"已经有一个，只是没用"。**

## 2. 抑制 CDIS 的是 k_eff，不是 PAQC（这条推翻了先前判断）

M=20、k=6 的完整 2×2（n=15，已剔除 WFG4，见 §4），相对 IGD 改进：

| 对比 | 全部 | WFG | DTLZ |
|---|---|---|---|
| CDIS 主效应（REMO → +CDIS） | **+6.2%** (11/15) | +5.7% (7/8) | +6.9% (4/7) |
| PAQC 主效应（REMO → +PAQC） | **+6.2%** (11/15) | +0.6% (6/8) | +12.5% (5/7) |
| CDIS 加在 PAQC 之上（+PAQC → full） | +4.0% (11/15) | +6.8% (6/8) | +0.9% (5/7) |
| PAQC 加在 CDIS 之上（+CDIS → full） | +4.4% (12/15) | +1.8% (6/8) | +7.3% (6/7) |

两个模块主效应相当，且各自在对方之上仍有增量 —— **部分冗余，不是一个吞掉另一个**。
分工清楚：**PAQC 主要在 DTLZ（+12.5%），CDIS 主要在 WFG（+5.7%、增量 +6.8%）。**

CDIS 增量按 k 分层（同为"加在 PAQC 之上"）：

| | 全部 | WFG | DTLZ |
|---|---|---|---|
| 在 k=6 | +4.0% | **+6.8%**（中位 +10.5%） | +0.9% |
| 在 k=30 | +2.2% | **+0.4%**（中位 +0.1%） | +4.3% |

M=10 同向：k=6 层 CDIS 主效应 WFG +6.5%（8/9）；k=15 层增量 WFG 只剩 +1.5%（6/9）。

**机制**：放大 k 与 CDIS 在 WFG 上是**替代品**。k 从 6 到 k_eff 时 WFG 改善 +10~12%
（两个宿主一致），CDIS 的 WFG 增量同时从 +6.8% 塌到 +0.4%。而 k 在 DTLZ 上有害
（−7.7% ~ −19.2%），CDIS 的残余价值就转到 DTLZ（+4.3%）。

→ 用户原问题"是不是我的 HPC 太强了所以候选模块看不出效果"：**不是 PAQC，是 k_eff。**
PAQC 只把 CDIS 从 +6.2% 压到 +4.0%，k_eff 把它的 WFG 增量压到近零。
这是一条可写的交互结论，且它把 CDIS 从"净效应为零的鸡肋"救回成"在宿主默认 k 下有效、
被我们自己的 k_eff 抢了功劳"。

## 3. 只挑 WFG 全系列：合规，但有两个必补的缺口

**先纠正我 09-08 上午说错的一条。**我说"挑 WFG 等于砍掉 CDIS 唯一站得住的证据（DTLZ7）"
—— 这**只在 k_eff 层成立**。在 k=6 层，CDIS 在 WFG 上是广谱有效的，不依赖单个问题：
M=10 逐问题 8 升 1 降（唯一降的是 WFG3 −7.3%），M=20 是 7/8。**WFG-only 反而对 CDIS 有利。**

写作指南 §16.5 的裁定很明确：**七篇对标文献的消融全部在子集上做，没有例外**，
消融/主实验实例数之比在 1/4 到 1/2（PIEA 63/144、DACKEA 21/69、KHM-EF 21/48、
MP-SAMaOEA 12/48）。所以挑数据集本身完全正当。WFG1-9 共 9/16 已经高于这个区间上限。
真正会被质疑的只有两件事：覆盖不了被测能力、没写为什么挑。

按指南 §16.5 的能力对照表核 WFG-only 的覆盖：

| 被测能力 | WFG 是否覆盖 |
|---|---|
| 收敛（多模态） | ✓ WFG4、WFG5（欺骗） |
| 不可分变量 | ✓ WFG6 |
| 偏置 | ✓ WFG7/WFG8、WFG1 |
| 不规则/不连续前沿 | ✓ WFG2 |
| 综合最难 | ✓ WFG9 |
| **干净的多样性基线** | **✗ 缺**（DTLZ2 是标准凹球面，WFG4 凹但同时多模态） |
| **退化前沿族** | △ 只有 WFG3；DTLZ5/DTLZ6 都被排除 |

**退化那一格是真正的风险。**指南 §16.5 明确列为"要避免的做法"第 1 条：
**别把主实验已暴露短板的题型从消融里拿掉**（点名 KHM-EF 砍掉线性和退化、
而它自己承认在这两类上弱，"审稿人对照两节会看出来"）。
主实验里退化族（WFG3/DTLZ5/DTLZ6）胜率 30.2%、WFG3 是 0胜2平30负 —— 这正是已暴露的短板。

**建议：WFG1-9 + DTLZ2 + DTLZ5 或 DTLZ6 之一 = 11 题。**
数据全都已经有了，零成本，只是选行。同时按指南 §16.3 的 MP-SAMaOEA 句式写一段选题理由
（一个问题对应一种被测能力），这是唯一有理由的两篇之一的做法。

**一个例外：k 那张表必须上全 16 题。**指南第 1399 行写明：判断"增益是不是只来自更大的 k"
**必须在完整消融集上做，不能只挑问题**，因为 k 是宿主参数而不是本文模块。
而 k 的效应恰好沿 WFG/DTLZ 分裂（WFG 全正、DTLZ 全负），只报 WFG 会让 k_eff 看起来
无条件正确 —— 这是审稿人最容易抓的那类选择性报告。

## 5. 顺带核到的代码事实（影响 m=3 消融列的设计）

`REMO_new2_..._Original.m:40`：`k_eff = min(Problem.N, max(6, ceil(1.5*Problem.M)))`。
**M=3 时 ⌈1.5×3⌉=5 < 6，取 6 —— 恰好等于 REMO 默认 k=6，k 因子自动消失。**
指南 §16.8 建议补 m=3 或 m=5 一列来支撑"增益随 m 上升"。
**m=3 是最干净的那一列**：k 因子自动退出，剩下的差异纯粹来自两个模块。
m=5 则是 k_eff=8，仍带 k 因子。
