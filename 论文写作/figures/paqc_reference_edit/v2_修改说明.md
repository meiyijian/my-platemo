# v2：Good group / Bad group 示意图

文件：`paqc_mechanism_v2_good_bad.png`。按用户四条反馈进行图像编辑，旧版本保留。

## 四项修改

1. 图例改为 **Good group** 与 **Bad group**，保留 Reference solution。
2. 右图显示多处方块变为绿色圆点，并保留 B 从圆点变为方块。绿色数量增加是图示分组配置的变化，不表示方法应当无限扩大 Good group。
3. 左图灰色 PF 曲线和 PF 字样均删除。右图 PF 保留，只有帮助读者理解的作用，不是算法评分输入。
4. 右侧说明改为 **Directional PBI assessment**，中文含义为“方向 PBI 评估”。论文模块名仍为 **PBI-Assisted Quality Classification (PAQC)**。

## 分组含义

- Good group 对应方法中的正组 C1。
- Bad group 在这张图中指剩余的非正组 C2，不表示数学上被支配的解，也不对应函数返回值 `bad_idx` 所代表的排名末端 25%。
- 当前源码将融合分数排名前 ceil(N*rGood) 的解放入正组，默认 rGood=0.25；其余解构成 C2。图中的参考解菱形首先表示参考解身份，不单独用圆形/方块编码它的分组。

## 科学使用边界

本轮新增转组和背景点属于概念图编辑，没有重新构造并逐点运行一个产生全部新标签的数值样本。**不能沿用 `paqc_correction_simple` 中的核验结果来证明本图新增转组正确。** 该图也不应作为“多个真实好解被准确救回”的实验结果。

图像编辑生成的点位不提供精确坐标保证。论文若要声称图中所有对应解的分组变化都由实际 PAQC 计算产生，需要另外使用相同点集计算标签并以矢量程序复现。当前图片适合讨论图意、布局和术语。

## 建议英文图注

**Conceptual illustration of PBI-assisted quality classification (PAQC).** Diamonds denote reference solutions, while green circles and gray squares indicate the good and bad groups, respectively. Here, the bad group means the complement of the selected good group, rather than Pareto-dominated solutions. (a) Representative-based classification supplies binary labels. (b) Directional PBI assessment supplies additional information for fused ranking, illustrating changes in group membership. The PF shown only in (b) is illustrative context and is not used for scoring. The additional membership changes are conceptual, not measured classification outcomes. The visualization concept follows the classification illustration in REMO; the layout and PAQC-specific content have been redrawn.
