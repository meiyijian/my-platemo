# PAQC 几何示意草图

本版参照用户提供的 REMO Fig. 3 几何图设计，用于讨论论文插图的视觉方案。参考原图的构图思想，正式论文应在图注或正文中注明来源，并补全 REMO 的正式文献信息。

两幅图对照参考解分类与 PAQC，保留 PF 作为外部位置参照。PF 不参与分类。黑色射线关联参考解，右图新增蓝色虚线表示独立参考方向；不能将原图中连接候选解与理想点的蓝色射线直接改称新增参考方向。

图中 Good group / Bad group 表示分组结果，不等于真实 Pareto 最优 / 被支配。A、B 的转入与 C 的转出是概念性演示，尚未由当前算法逐点计算验证；本版不能沿用先前八解或十二解数值示例的核验结论，也不能作为改进有效性的实验依据。人工生成的几何位置与局部边界不属于公式精确绘制。

正式定稿时需使用一组经评分与融合排序核验的点替换概念位置，并按实际正组配额核验数量；保留简洁视觉设计即可。右侧名称 PAQC；附加信息标为 Directional PBI assessment。

英文图注草案：Conceptual illustration of representative-based classification and PBI-assisted quality classification (PAQC). Additional reference directions provide directional PBI information for the fused grouping decision. The Pareto front is shown only as an external reference. The displayed reassignment is schematic and does not represent a numerically validated example.

生成方式：内置图像编辑工具；参考输入为用户提供的 REMO Fig. 3。新提供的高清图用于辨认原图中的候选射线、投影与分类边界。
