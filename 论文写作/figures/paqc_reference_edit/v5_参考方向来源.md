# 自适应参考方向的来源

当前 PBIQualityClassification.m 第 38 行规定 M<=3 或 N<50 时使用均匀参考方向；其他情况尝试根据第一非支配层构造自适应方向，并有数量不足等回退条件。第 174 行按原始目标向量归一化构造 V，不是按减去理想点后的向量构造。

本次图示用二维空间说明自适应分支的几何含义，不代表二维问题实际执行该分支。设 O=Z，避免将原始目标向量与相对理想点的向量混淆。P1、P2 是示例中的非支配解，放在 PF 上仅表示理想化情形；算法不读取真实 PF。二者进入 Good group 是例子设定，非支配解身份不保证进入融合排名正组。

建议正文：为明确方向信息的来源，图中引入非支配解 P1 和 P2。对于自适应参考方向分支，算法将当前非支配解的目标向量归一化，以构造方向集合。右图中经过 P1 和 P2 的蓝色虚线分别示意相应方向。与由参考解 R1、R2 生成二元标签的作用不同，这些方向用于计算候选解的连续 PBI 质量得分，并参与后续融合排序。为便于展示，图中设理想点与原点重合，并将 P1、P2 绘于 PF 上；真实 PF 不参与算法计算。

本图仍为概念性草图，分组变化与局部边界尚未逐点数值核验。
