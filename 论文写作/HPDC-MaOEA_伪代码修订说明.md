| 修订项 | 处理结果 |
|---|---|
| 算法组织 | Algorithm 1 为总体框架，新增 Algorithm 2 展示混合 PBI 分组，原候选选择算法顺延为 Algorithm 3。 |
| 行尾 Section / Algorithm 注释 | 全部删除。主框架说明段统一引用两个子算法；保留计算步骤中必要的公式引用。 |
| 昂贵评估计数 | 显式初始化 FE、更新 FE，主算法统一在真实评估前截断剩余预算。 |
| 模型接口 | 明确关系模型和指标模型记号，并传入候选选择过程；指标模型不可用时记为空。 |
| 常规算法流程 | 删除无训练对时反复 continue 的实现式异常分支，按方法部分展示有效训练数据下的常规流程；保留空候选批次的直接变异后备步骤。 |
| 候选积累 | 使用候选列表和独立累计生成计数，结束后得到去重候选池。 |
| 分位筛选 | 明确指标分位阈值、两个模式的最小数量补齐，以及“先确定 n_b，再选择批次”的顺序。 |
| 贪心选择 | 明确首个候选最大化探索获取分数，后续逐个按质量与距离准则加入。 |
| 正文同步 | 统一先抽模式再构建候选池的顺序、当前种群的指标训练范围、初始化规模与目标种群规模的含义。 |

没有把实现中的小池固定常数、异常捕获或训练配置逐项塞入算法框。分组算法继续引用正文的数学定义，并以简短步骤呈现“连续分数—代表解标签—融合—排序分组”。
