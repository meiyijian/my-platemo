## 计算与表格

`build_tables.py` 从保存的 Excel 生成两张逐问题表、模块对照表、k 对照表及来源快照。`source_snapshot.json` 包含文件哈希、原始类名、单元格位置及排除标识；`summary.json` 保存重新计算的统计汇总。

所有箭头 A→B 的方向统一为 B 相对 A。均值胜/负只是逐问题均值比较；导出胜/负/无差异只计数文件中已有的直接比较符号，不由均值与标准差推算 p 值。反向读取比较时交换胜负，不改变无差异计数。没有直接导出的比较留空。

G 为各问题“变更前均值/变更后均值”的几何平均，每个问题等权，G>1 有利于变更后配置。不能把 G−1 直接解释成平均 IGD 降低百分比。

## 组会可讲的结论

1. 固定表中较大的 k 后，分类变体仍有收益。M10 的均值胜/负为 14/2，M20 为 11/4；原表报告的比较结果分别为 8/1/7、10/2/3。这支持继续研究分类方案，不能单独归因于连续评分。
2. 候选模块加在分类模块之上，收益较小且依赖问题。两个目标数下 G 均约为 1.028，原表各有 3 个有利差异、1 个不利差异；DTLZ7 的均值分别降低 30.0% 和 29.2%。DTLZ5 则变差，20 目标 WFG6 几乎不变。
3. k 增大不是普遍有效。DTLZ 组的几何均值比例均低于 1，WFG 组均高于 1。20 目标 Full 虽有 8 个问题均值改善、7 个变差，但总体 G=0.978，说明不能只数胜场。
4. 不写“协同增强”“两个模块已得到因果验证”，也不把 Original 的证据直接归到当前 Full。
