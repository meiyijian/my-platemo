### 关键踩坑（可复用）
1. MATLAB R2021b `ismember(NaN,[0 1 NaN])` 返回 false → NaN 标志列需 `isnan(x)|ismember(x,[0 1])`。
2. `ParameterSet` 空值回退默认（use_indicator=[]→1）；n_min/n_max 必须显式传 1 才能让 maxFE=35 的 smoke 有 3 代。
3. `knownRejected = rejected(all(...))` 中 all() 返回标量会只取第一个元素 → 必须用 `rejected(logicalVector)`。
4. modeStream（run=1）首个 rand=0.7087→explore，故 smoke 首代非指标。
5. git bash 的 rm 对项目内文件触发 safe-delete 需 Windows 绝对路径。
