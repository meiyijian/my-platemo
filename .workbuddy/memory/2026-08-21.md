## PCSAEA 源码梳理（对比算法，Compare_REMO_PCSAEA 在用）
- 位置：`PlatEMO-master/PlatEMO/Algorithms/Multi-objective optimization/PC-SAEA/`，共 8 文件（PCSAEA.m / PCSAEA_N100.m 为同一算法的 N 参数变体）。
- 核心思想：用**成对比较分类代理**（PNN 概率神经网络）替代回归代理。分类器学"xi 是否优于 xj"，而非预测目标值。
- 主循环：CalFitnessPC（SDE 多样性 + SPEA2 式 R/D 加权，rate=FE/maxFE 随预算切换收敛/多样性权重）→ 取 top ¼N 好解(标签2) + ¼N 差解(标签1) 为平衡样本集，Pa=好解子集作参考点 → DataProcess 3/4:1/4 分层划分 → RBFNNPC.train 两两配对 (xi,xj) 拼接 2D 输入训练 PNN → lastpredict 对 (候选,Pa) 正反双向各预测一次相减打分（0→1.5 不确定）→ 可靠性门控（Error1<1-δ 信正标签≥0.95；Error2<1-δ 信负标签≤-0.95；否则随机）→ GA 爬山 wmax=floor(gmax/lnum) 轮找候选 → 真实评估入 Arc → SPEA2 环境选择截断回 N。
- 参数：δ=0.8（可靠性阈值）、gmax=3000（代理侧 GA 迭代预算）、N=max(11D−1, N)。
- 观察：error2 分支按"最差"打分选解，与 error1 分支对称但语义上是负向搜索，疑似论文中的探索性设计；源码中 Error2 分母用 length(TestOut) 而非 validIndex 个数，疑似笔误。
- 对 AdaMaO 的对照价值：分类/判别式代理（成对偏好）vs AdaMaO 指标子系统（DRVC 判别），机制层面可比，可支撑 related work 或消融对照叙述。

## HPC 理论分析文档（论文理论部分写作准备稿）
- 产出：`REMO_new2_AdaMaO/notes/2026-08-21-HPC理论分析-从混合PBI到阶段感知质量分层.md`。
- 核心故事重定义：HPC 不再是"两个互补 PBI 融合"，而是 **stage-aware quality stratification**（连续 PBI 排序弥补二值锚点标签分辨率不足 + 阶段权重早期允许连续几何修正标签、后期强化锚点组间偏好）。明确不主张"HPC 是新全局 Pareto indicator"。
- 三个可证明性质（全部由公式推出，非猜测）：
  1. 组内排序保持：同标签解 h_i−h_j=α(s_i−s_j)，α>0 时保留连续 PBI 排序；
  2. 跨标签偏好转移：h_i−h_j=α(s_i−s_j)+(1−α)，t=FE/maxFE，t>0.5 后 l=1 一定排在 l=0 前（阈值 −t/(1−t)）；
  3. 有界过渡：|h_i−s_i|≤t，|h_i−l_i|≤1−t，即 continuous→anchor constrained 的连续有界过渡。
- 叙事落点：Better quality stratification → better training-pair construction（GetRelationPairs 对 C1−C1 打 0，HPC 只影响"谁进 C1"的选择性，不提供 good-good 内部精确序）。
- 设计假设（非定理，需实验验证）：Precision_score(t) vs Precision_label(t) 随 FE 变化，early score 好 / late label 好 则 α=1−t 故事成立。
- 待办：统一坐标原点（源码 HybridPBI_Classification.m L63、GetOutput_PBI.m L96 已自标注 cos 关联未减 Zmin 而 PBI 投影减了）；Good-group Precision 实验作为中间因果环节证据；画 stage-aware preference transition 示意图。
- 对标文献：GRE-MOEA（2025, grid ranking + relation model）、R²AEA（2025, 两阶段 surrogate + uncertainty/performance infill）、原始 REMO（pairwise relation + voting-scoring）——均以 mechanism analysis + ablation + 统计验证支撑，无需全局收敛定理。
