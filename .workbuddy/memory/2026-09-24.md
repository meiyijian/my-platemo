## NoBatchDist 版 pMix 敏感性实验（论文 pMix 表重跑）—— 已启动

**背景**：论文 `论文写作/experiments/pmix_historical_table.tex` 的 pMix 表标题写的是
"Historical Lambdat030 sensitivity ... (batch-distance version; IGD)"，用的是**带批内距离项**
的旧 `...Lambdat030`。用户要求用当前 Full 实现 `..._NoBatchDist` 的五个固定 pMix 派生类
重跑同一张表，使论文里的 pMix 敏感性与当前方法版本一致。

**口径（用户逐项确认）**：6 题（DTLZ2/4/7、WFG1/3/8）× M=**10/20** × 5 档
（0/0.25/0.50/0.75/1.00）× 20 跑 = **1200 跑**；N=100、D=30、maxFE=300、SaveCount=30；
SeedBase M10=21260912 / M20=22260912（`base+1000*题号+run`）；threads=1；
**在线同步算 IGD + IGDp**（harness `ExtraMetrics`，比事后串行 merge 划算）。

**框架**：`PlatEMO/Experiments/REMO_UniformMix_Pruned_Weighted_Lambdat030_NoBatchDist_pMixSweep/`
- `run_pMixSweepNoBatchDist.m` 单切片 runner
- `missing_runs.py` 输出缺失切片（TAB：pTag/M/part/lo/hi）
- `driver.sh` 14 路错峰 25 s，每轮重算缺口，尾部跑校验
- `verify_pMixSweepNoBatchDist.m` 1200 文件校验 + 逐跑 CSV + 与 Full 的逐位对照
- `README.md`

调度：120 切片（10 跑/切片），后台任务 `iKuQiI`；巡检自动化
`c97ea7d7-54b3-4d8d-b446-8f6a60698f36`（每小时，有效到 09-24 14:00）。

**跑前已核对（3 项）**
1. 五变体与 Full 的 `private/` **同构**；主类唯一差异 = `pMix` 硬编码 + 参数 5→4 `{3000,0.25,0.70,6}`。
2. 变体仍调用 `NoBatchDistWeightedBatchSelection`（无批距项），没回退到带批距版本。
3. `ResolveUniformMixMode.m` / `PrunedIndicatorSelection.m` 在 Lambdat030 与 NoBatchDist
   两处**逐字节相同** → 靠 path 解析不会版本串味。
   ⇒ 结论：**PMix050 应与 Full 逐位一致**，verify 脚本会自动做这个对照（免费的正确性证据）。

**踩坑（3 个）**
1. 🔴 **类名大小写**：变体是 `..._NoBatchDist_PMix000`（**大写 P**），旧带批距族是
   `..._Lambdat030_pMix000`（小写 p）。按旧惯例拼小写 → harness 报
   `Cannot find class REMO_..._NoBatchDist_pMix000`。第一次 smoke 就抓到了。
2. 🔴 **切片表 CR**：python 在 Windows 上 stdout 默认 `\r\n`，bash `read` 会把 `\r` 带进
   最后一个字段（MATLAB 会收到 `10\r`）。修法 = `sys.stdout.reconfigure(newline='\n')`
   + driver 侧 `| tr -d '\r'` 兜底。
3. ⚠️ **沙箱内 MATLAB `-batch` 退出必崩**：`Access violation` (0xc0000005)，栈在
   `addons_registry_core → libxml2 → httpclient`（Add-On 联网检查，沙箱内无网络）。
   **崩在 MAT 写盘与 CSV 写完之后的 17 秒**，数据安全；driver 不检查退出码，不受影响。
   `%TEMP%` 下已有 130+ crash dump。

**Smoke 实证**：PMix000 / M=20 / DTLZ2 / run1 →
IGD 1.43179→1.19075、IGDp 1.16504→0.83286、runtime 260.1 s、wall 262.7 s；
MAT 含 `result` + `metric{runtime,IGD,IGDp}`（30 快照全有限）。

**ETA**：池内单跑 wall 约 260–350 s（含 IGDp）→ 1200 跑 / 14 路 ≈ **9–10 h**。

**未使用**：`..._NoBatchDist_PMix_Sensitivity_M20`（更早铺的 **16 题 × M=20 = 1600 跑**版，
README 写明 16 题），与本轮 6 题口径不同，未启动 —— 若之后要全系列 pMix 敏感性可复用。
