## DR_SAEA 昂贵超多目标算法（PlatEMO）

**任务**：基于 PlatEMO 平台实现模块化昂贵超多目标优化算法 DR_SAEA（降维 + 代理 + 填充采样）。

**阶段**：✅ 已实现 + 端到端验证通过。

**位置**：`PlatEMO-master/PlatEMO-master/PlatEMO/Algorithms/Multi-objective optimization/DR_SAEA/`

**文件清单**（6 个）：
- `DR_SAEA.m` 主算法类
- `reduceObjectives.m` 目标降维（random / correlation 层次聚类）
- `buildSurrogate.m` 代理（Kriging / RBF / Relation 留接口），train + predict 同名重载
- `infillSelect.m` 填充采样（balanced / exploitation / exploration）
- `computeEHVI.m` 2D EHVI 闭式
- `README_汇报.md` 完整汇报文档

**端到端验证**（MATLAB 真实运行）：
- DTLZ2 M=3 D=5 maxFE=50 ✅
- DTLZ2 三种策略切换 ✅
- **DTLZ5 M=8 D=10 maxFE=300 ✅**：Archive=300, ND=83, HV=0.0287，~100s

**关键调试经验**（已写入 README）：
1. `applyReduction` 在外部无法直接调用，改为统一入口 `reduceObjectives(PopObj, K, Strategy, Seed, GroupMap, Fmin, Fmax)` 重载
2. `buildSurrogate` 用同一函数暴露 train/predict 两种重载，靠 `iscell(Dec) && isstruct(Dec{1})` 判别模式
3. predict 重载签名 `buildSurrogate(Models, X, SurrogateType, TrainDec)`，第 4 个位置参数在签名中叫 `D` 槽位，需注意参数名覆写
4. SurrogateType 在 predict 重载中**不能**用 `D` 槽位的 TrainDec 覆写，否则 `switch` 表达式变为矩阵
5. RBF 自实现以避免对 ADSAPSO 目录的运行时依赖
6. 相关性层次聚类用自实现平均连接 linkage，不依赖 Statistics Toolbox
