### 踩坑
- 🔴 **不要编辑正在运行的 bash 脚本**：bash 按偏移增量读取脚本，中途改文件会让它从错位处继续解析（本次报 `line 28: eep: command not found` + `syntax error near 'done'`，把 5 个等价性验证进程连同 kill 掉）。要改就先停下脚本。
- 🔴 **切片表不能用空格分隔的字段**：`read -r alg runs tag` 会把 `[1 2 3 4]` 拆成 `[1` + `2 3 4]`（首次正式启动因此空转 30 s，MATLAB 语法错误秒退）。修法：切片表改 tab 分隔 + `IFS=$'\t'`，runs 用 MATLAB 冒号语法 `1:4`（字段内无空格）。**启动长跑前先干跑一遍解析循环核对字段**。
- Git Bash 的 `pwd` 返回 `/d/...`，直接传给 MATLAB 无效（会静默不生效或生成 `D:\d\...`）→ 用 `pwd -W`。
- `@(v)[]` 作 outputFcn 会报 `MATLAB:TooManyInputs`（NotTerminated 传 2 个参数）→ 必须 `@(varargin)[]`。
- `save` 目录 `D:\REMOandDREMO测试集\5目标\n3\` 由 harness 的 `mkdir` 自动创建（多层一次性建好）。
